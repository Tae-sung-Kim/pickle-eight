# 오늘의 운세 / 운세 앱 개발 가이드

오늘의 운세(일일 운세)와 일반 운세를 만들기 위해 필요한 정보, 입력값, 규칙, 구현 방법을 정리한 문서.

> 운세는 과학적으로 증명된 것이 아니다. 앱에서는 **오락 / 참고용**임을 반드시 표시한다.

---

## 1. 운세 종류와 난이도

| 종류 | 필요한 입력 | 난이도 | 설명 |
|---|---|---|---|
| 별자리 운세 | 생일(월/일) | 쉬움 | 12별자리별 공통 문구 |
| 띠 운세 | 출생 연도 (입춘/설날 기준 처리) | 쉬움 | 12띠별 공통 문구 |
| 오늘의 운세 (간이) | 생년월일 | 보통 | 생년월일 + 오늘 날짜로 결과 생성 |
| 사주 기반 운세 | 생년월일시, 성별, 양/음력 | 어려움 | 사주 8글자 + 오늘 일진 관계로 해석 |
| 토정비결 / 신년운세 | 생년월일, 음력 변환 | 어려움 | 연 단위 운세, 별도 규칙 필요 |
| 궁합 | 두 사람 정보 | 어려움 | 사주 간 관계 계산 |

**추천 순서**: 별자리/띠 → 간이 오늘의 운세 → 사주 기반 운세

---

## 2. 입력값 (사용자에게 받을 정보)

### 2.1 필수

| 필드 | 형식 | 비고 |
|---|---|---|
| 생년월일 | YYYY-MM-DD | 양력/음력 선택 필요 |
| 달력 구분 | 양력 / 음력 | 음력이면 윤달 여부도 받는다 |
| 윤달 여부 | boolean | 음력일 때만 |

### 2.2 선택 (사주 기반일 때 사실상 필수)

| 필드 | 형식 | 비고 |
|---|---|---|
| 태어난 시간 | HH:mm 또는 12시진 선택 | 모르면 "모름" 허용 (시주 제외) |
| 성별 | 남 / 여 | 대운 계산 방향에 사용 |
| 출생 지역 | 시/도 | 지역별 시간 보정 사용 시 |
| 이름 | 문자열 | 필수 아님. 표시용 |

### 2.3 UX 팁

- 시간을 모르는 사람이 많다. **"시간 모름" 옵션**을 꼭 둔다. 이 경우 연/월/일 3기둥만 사용.
- 음력 입력 시 양력 변환 결과를 확인용으로 보여준다.
- 생년월일은 민감 정보다. 저장은 최소화한다 (아래 9장 참고).

## 3. 핵심 개념 (사주 기반)

### 3.1 천간 10개

| 번호 | 한자 | 한글 | 오행 | 음양 |
|---|---|---|---|---|
| 0 | 甲 | 갑 | 목 | 양 |
| 1 | 乙 | 을 | 목 | 음 |
| 2 | 丙 | 병 | 화 | 양 |
| 3 | 丁 | 정 | 화 | 음 |
| 4 | 戊 | 무 | 토 | 양 |
| 5 | 己 | 기 | 토 | 음 |
| 6 | 庚 | 경 | 금 | 양 |
| 7 | 辛 | 신 | 금 | 음 |
| 8 | 壬 | 임 | 수 | 양 |
| 9 | 癸 | 계 | 수 | 음 |

### 3.2 지지 12개

| 번호 | 한자 | 한글 | 띠 | 오행 | 음양 |
|---|---|---|---|---|---|
| 0 | 子 | 자 | 쥐 | 수 | 양 |
| 1 | 丑 | 축 | 소 | 토 | 음 |
| 2 | 寅 | 인 | 호랑이 | 목 | 양 |
| 3 | 卯 | 묘 | 토끼 | 목 | 음 |
| 4 | 辰 | 진 | 용 | 토 | 양 |
| 5 | 巳 | 사 | 뱀 | 화 | 음 |
| 6 | 午 | 오 | 말 | 화 | 양 |
| 7 | 未 | 미 | 양 | 토 | 음 |
| 8 | 申 | 신 | 원숭이 | 금 | 양 |
| 9 | 酉 | 유 | 닭 | 금 | 음 |
| 10 | 戌 | 술 | 개 | 토 | 양 |
| 11 | 亥 | 해 | 돼지 | 수 | 음 |

### 3.3 오행 관계

- **상생**: 목 → 화 → 토 → 금 → 수 → 목
- **상극**: 목 → 토, 토 → 수, 수 → 화, 화 → 금, 금 → 목

### 3.4 60갑자

- 천간 10개와 지지 12개를 순서대로 짝지은 60개 조합.
- 0 = 갑자, 1 = 을축, 2 = 병인 ... 59 = 계해.
- 인덱스 `n`의 천간 = `n % 10`, 지지 = `n % 12`.

### 3.5 사주 4기둥 (사주팔자)

| 기둥 | 기준 | 의미(관례) |
|---|---|---|
| 연주(年柱) | 입춘 기준 연도 | 조상, 어린 시절 |
| 월주(月柱) | 절기 기준 월 | 부모, 청년기, 사회 환경 |
| 일주(日柱) | 일진(日辰) | 나 자신, 배우자 |
| 시주(時柱) | 태어난 시각 | 자식, 말년 |

- **일간(日干)** = 일주의 천간. 사주 해석에서 "나"를 뜻한다.

## 4. 계산 규칙

### 4.1 연주

- 기준: **입춘**(양력 2월 4일 전후, 해마다 시각이 다름). 입춘 이전 출생이면 전년도로 계산.
- 공식: `index = (year - 4) mod 60` (year는 입춘 보정 후 연도). 0 = 갑자.
- 검증: 2000년 → 경진년.

### 4.2 월주

- 월지는 **절기**로 정한다 (음력 달이 아님).

| 월지 | 시작 절기 | 대략 양력 |
|---|---|---|
| 인(寅) | 입춘 | 2/4 |
| 묘(卯) | 경칩 | 3/6 |
| 진(辰) | 청명 | 4/5 |
| 사(巳) | 입하 | 5/6 |
| 오(午) | 망종 | 6/6 |
| 미(未) | 소서 | 7/7 |
| 신(申) | 입추 | 8/7 |
| 유(酉) | 백로 | 9/8 |
| 술(戌) | 한로 | 10/8 |
| 해(亥) | 입동 | 11/7 |
| 자(子) | 대설 | 12/7 |
| 축(丑) | 소한 | 1/6 |

- 월간은 **연간**으로 정한다 (오호둔).

| 연간 | 인월(첫 달)의 월주 |
|---|---|
| 갑, 기 | 병인 |
| 을, 경 | 무인 |
| 병, 신 | 경인 |
| 정, 임 | 임인 |
| 무, 계 | 갑인 |

- 인월 이후는 월간이 천간 순서대로 하나씩 올라간다.

### 4.3 일주 (일진)

- 율리우스 일수(JDN) 기준 공식:
  `index = (JDN + 49) mod 60` (JDN은 해당 날짜 정오 기준 정수). 0 = 갑자.
- 검증: 2000-01-01 → JDN 2451545 → index 54 → 무오일.
- 날짜 경계는 보통 **자정(00:00)** 기준으로 일진을 바꾼다. (23시 이후를 다음 날로 보는 학파도 있음. 아래 4.5 참고)

### 4.4 시주

| 시지 | 시간대 |
|---|---|
| 자(子) | 23:00 ~ 00:59 |
| 축(丑) | 01:00 ~ 02:59 |
| 인(寅) | 03:00 ~ 04:59 |
| 묘(卯) | 05:00 ~ 06:59 |
| 진(辰) | 07:00 ~ 08:59 |
| 사(巳) | 09:00 ~ 10:59 |
| 오(午) | 11:00 ~ 12:59 |
| 미(未) | 13:00 ~ 14:59 |
| 신(申) | 15:00 ~ 16:59 |
| 유(酉) | 17:00 ~ 18:59 |
| 술(戌) | 19:00 ~ 20:59 |
| 해(亥) | 21:00 ~ 22:59 |

- 시간은 **일간**으로 정한다 (오서둔).

| 일간 | 자시(첫 시)의 시주 |
|---|---|
| 갑, 기 | 갑자 |
| 을, 경 | 병자 |
| 병, 신 | 무자 |
| 정, 임 | 경자 |
| 무, 계 | 임자 |

### 4.5 학파별로 갈리는 부분 (앱 정책으로 정해야 함)

| 쟁점 | 선택지 | 추천 |
|---|---|---|
| 연 경계 | 입춘 기준 / 설날(음력 1/1) 기준 | 사주는 입춘, 띠는 사용자 안내 후 선택 |
| 자시 처리 | 23시부터 다음 날 (야자시 구분) / 0시부터 | 한 가지로 고정하고 안내 문구 표시 |
| 출생지 시간 보정 | 보정함 / 안 함 | MVP는 안 함, 설정 문구로 안내 |
| 과거 표준시 | 한국 표준시는 과거에 여러 번 바뀜 (예: 1954~1961년 UTC+8:30) | 정밀도가 필요하면 별도 보정 테이블 |
| 서머타임 | 과거 한국에서 시행된 해가 있음 | 만세력 라이브러리/데이터 확인 |

> 위 항목은 정답이 하나가 아니다. 앱 안에서 **어떤 기준을 썼는지 명시**하는 것이 중요하다.

## 5. 오늘의 운세 생성 방법 (3가지)

### 방법 A. 시드 기반 결정적 랜덤 (가장 쉬움)

- 입력: `생년월일 + 오늘 날짜(KST)` 문자열 → 해시 → 시드.
- 시드로 난수를 만들어 점수/문구를 고른다.
- **같은 사람은 같은 날 항상 같은 결과**, 날짜가 바뀌면 결과가 바뀐다.
- 장점: 구현 간단, 서버 저장 불필요.
- 단점: 전통 이론과 무관한 순수 랜덤. 재미용.

### 방법 B. 사주 규칙 기반 (전통 이론 활용)

1. 사용자 사주에서 **일간**을 구한다.
2. 오늘 날짜의 **일진(천간/지지)**을 구한다.
3. 일간 vs 오늘 일진 천간의 관계 → **십신** 산출.
4. 십신별 기본 문구/점수 테이블로 결과 생성.
5. 필요하면 지지 관계(합, 충)와 오행 균형도 가산.

- 장점: 사용자마다 근거 있는 차이가 생김.
- 단점: 구현량 많음, 해석 데이터 작성 필요.

### 방법 C. AI 문구 생성 하이브리드

- 방법 A 또는 B로 **점수/키워드/십신**을 먼저 확정한다.
- 확정된 값을 프롬프트로 넘겨 **자연스러운 문장**만 AI가 쓴다.
- 같은 입력이면 결과가 흔들리지 않도록 **하루 단위로 캐시**한다.
- 장점: 문구 다양성, 데이터 작성 부담 감소.
- 단점: 비용, 검수 필요, 부적절한 표현 방지 필요.

**추천**: MVP는 A, 이후 B를 추가하고, 문구는 C로 다듬기.

## 6. 십신 계산 규칙 (방법 B)

일간(나)과 대상 천간의 관계:

| 관계 | 같은 음양 | 다른 음양 |
|---|---|---|
| 같은 오행 | 비견 | 겁재 |
| 내가 생함 | 식신 | 상관 |
| 내가 극함 | 편재 | 정재 |
| 나를 극함 | 편관 | 정관 |
| 나를 생함 | 편인 | 정인 |

### 6.1 십신 기본 의미 (오늘의 운세 문구용)

| 십신 | 키워드 | 오늘의 분위기 예시 |
|---|---|---|
| 비견 | 동료, 경쟁, 자립 | 주도적으로 움직이기 좋지만 고집 주의 |
| 겁재 | 경쟁, 지출, 변동 | 충동 소비와 다툼 주의 |
| 식신 | 여유, 표현, 먹을 복 | 편안하고 창의적인 하루 |
| 상관 | 재능, 표현, 반항 | 말실수 주의, 아이디어는 좋음 |
| 편재 | 활동적 재물, 기회 | 기회와 만남이 많은 날 |
| 정재 | 안정적 재물, 성실 | 꾸준함이 보상받는 날 |
| 편관 | 압박, 도전, 책임 | 긴장되는 일정, 인내 필요 |
| 정관 | 규칙, 인정, 명예 | 평가받기 좋은 날 |
| 편인 | 직관, 변칙, 고독 | 생각이 많아지는 날 |
| 정인 | 도움, 학습, 안정 | 도움받기 좋고 공부에 유리 |

> 위 해석과 점수는 **앱 자체 설정**이다. 학파별로 길흉 판단이 다르므로 서비스 톤에 맞게 정하고, 단정적 표현은 피한다.

### 6.2 점수 가중치 예시 (앱 자체 규칙)

```json
{
  "정재": { "total": 80, "money": 85, "love": 70, "work": 75, "health": 70 },
  "정관": { "total": 78, "money": 70, "love": 72, "work": 85, "health": 70 },
  "정인": { "total": 76, "money": 65, "love": 70, "work": 75, "health": 75 },
  "식신": { "total": 82, "money": 72, "love": 78, "work": 70, "health": 80 },
  "겁재": { "total": 50, "money": 40, "love": 55, "work": 55, "health": 60 }
}
```

- 값은 예시이므로 직접 조정한다.
- 점수는 **기본값 ± 시드 기반 작은 변동(예: ±5)**을 주면 단조로움이 줄어든다.

## 8. 별자리 / 띠 운세 (간이 버전)

### 8.1 별자리 날짜 경계

| 별자리 | 기간 |
|---|---|
| 염소자리 | 12/22 ~ 1/19 |
| 물병자리 | 1/20 ~ 2/18 |
| 물고기자리 | 2/19 ~ 3/20 |
| 양자리 | 3/21 ~ 4/19 |
| 황소자리 | 4/20 ~ 5/20 |
| 쌍둥이자리 | 5/21 ~ 6/21 |
| 게자리 | 6/22 ~ 7/22 |
| 사자자리 | 7/23 ~ 8/22 |
| 처녀자리 | 8/23 ~ 9/22 |
| 천칭자리 | 9/23 ~ 10/22 |
| 전갈자리 | 10/23 ~ 11/22 |
| 사수자리 | 11/23 ~ 12/21 |

> 경계일은 출처마다 하루 정도 차이가 날 수 있다. 하나로 고정해서 사용한다.

### 8.2 띠 계산

- `띠 인덱스 = (연도 - 4) mod 12` → 지지 표의 순서와 동일 (0 = 쥐).
- 연도는 입춘 기준 또는 설날 기준 중 하나를 정해서 쓴다.

### 8.3 생성 방식

- 하루 12개 문구를 **매일 한 번 생성하고 캐시** (모든 사용자 공통).
- 또는 방법 A로 `(별자리 + 날짜)` 시드를 써서 서버 없이 생성.

## 10. 핵심 로직 예시 (TypeScript)

```ts
const STEMS = ["갑","을","병","정","무","기","경","신","임","계"];
const BRANCHES = ["자","축","인","묘","진","사","오","미","신","유","술","해"];
const ELEMENTS = ["목","화","토","금","수"];

// 천간 오행 / 음양
const stemElement = (i: number) => Math.floor(i / 2);   // 0:목 1:화 2:토 3:금 4:수
const stemYang = (i: number) => i % 2 === 0;            // 짝수 = 양

// 양력 날짜 -> 율리우스 일수 (정오 기준 정수)
function toJDN(y: number, m: number, d: number): number {
  const a = Math.floor((14 - m) / 12);
  const yy = y + 4800 - a;
  const mm = m + 12 * a - 3;
  return d + Math.floor((153 * mm + 2) / 5) + 365 * yy
    + Math.floor(yy / 4) - Math.floor(yy / 100) + Math.floor(yy / 400) - 32045;
}

// 일주: 60갑자 인덱스 (0 = 갑자)
function dayPillarIndex(y: number, m: number, d: number): number {
  return (toJDN(y, m, d) + 49) % 60;
}

// 연주: 입춘 보정은 호출 전에 처리 (year = 보정된 연도)
function yearPillarIndex(adjustedYear: number): number {
  return (((adjustedYear - 4) % 60) + 60) % 60;
}

const pillarName = (idx: number) => STEMS[idx % 10] + BRANCHES[idx % 12];

// 십신 계산: me = 일간 인덱스, target = 대상 천간 인덱스
function tenGod(me: number, target: number): string {
  const rel = (stemElement(target) - stemElement(me) + 5) % 5;
  const same = stemYang(me) === stemYang(target);
  switch (rel) {
    case 0: return same ? "비견" : "겁재";
    case 1: return same ? "식신" : "상관";
    case 2: return same ? "편재" : "정재";
    case 3: return same ? "편관" : "정관";
    default: return same ? "편인" : "정인";
  }
}

// 시드 기반 난수 (같은 입력 = 같은 결과)
function hash(str: string): number {          // FNV-1a
  let h = 2166136261;
  for (let i = 0; i < str.length; i++) {
    h ^= str.charCodeAt(i);
    h = Math.imul(h, 16777619);
  }
  return h >>> 0;
}
function mulberry32(seed: number) {
  return () => {
    seed |= 0; seed = (seed + 0x6D2B79F5) | 0;
    let t = Math.imul(seed ^ (seed >>> 15), 1 | seed);
    t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}

// 오늘의 운세 (간이): 날짜는 KST 기준 문자열 사용
function dailyFortune(birth: string, todayKST: string) {
  const rand = mulberry32(hash(birth + "|" + todayKST));
  const score = (base: number) =>
    Math.max(0, Math.min(100, Math.round(base + (rand() - 0.5) * 10)));
  return { total: score(70), money: score(70), love: score(70) };
}
```

> 검증 포인트: `dayPillarIndex(2000, 1, 1)`은 54 (무오일)가 나와야 한다. 개발 중 테스트로 꼭 넣는다.

## 11. 사용할 수 있는 데이터 / 라이브러리

| 용도 | 후보 | 비고 |
|---|---|---|
| 음력 ↔ 양력 | `korean-lunar-calendar` (npm) | 한국 음력 기준 |
| 음력/절기/간지 | `lunar-javascript` (npm) | 중국 달력 기반. 24절기, 간지 제공. 한국 표준시와 절기 시각 차이 확인 필요 |
| 공공 데이터 | 한국천문연구원 음양력 정보 / 특일 정보 (공공데이터포털 Open API) | 24절기, 음양력 변환, 간지 정보 제공. 제공 항목과 사용량 제한은 직접 확인 |
| 직접 구현 | 절기 테이블 JSON | 연도별 24절기 시각을 미리 저장 |

**선택 가이드**
- MVP: 라이브러리로 음력 변환 + 직접 구현한 일진 공식.
- 정확도가 중요하면: 절기 시각은 천문연 데이터로 검증.
- **라이브러리 결과는 반드시 알려진 날짜 몇 개로 검증**한 뒤 사용한다.

## 12. 규칙 (앱 구현 체크리스트)

| 규칙 | 내용 |
|---|---|
| 일관성 | 같은 입력 + 같은 날짜 = 같은 결과 (시드 고정) |
| 날짜 기준 | 한국 시간(KST) 자정에 갱신 |
| 시간대 처리 | 서버/브라우저 시간대에 의존하지 않고 KST로 명시 변환 |
| 시간 모름 | 시주 없이 3기둥으로 계산, 결과에 안내 |
| 기준 명시 | 입춘/자시/보정 기준을 "계산 기준" 화면에 표시 |
| 점수 범위 | 0~100 고정, 극단값 줄이기 (30~95 권장) |
| 톤 | "~일 수 있어요" 식 완곡 표현, 단정/공포 조성 금지 |
| 민감 주제 | 건강, 죽음, 사고, 투자 등은 단정 금지. 전문가 상담 안내 |
| 면책 | "오락 및 참고용" 문구 항상 표시 |
| 캐시 | 하루 단위로 결과 캐시 (AI 문구 사용 시 필수) |

## 14. 주의사항

- **정확성**: 만세력 계산은 절기 시각, 표준시 변경, 서머타임 때문에 틀리기 쉽다. 알려진 날짜로 테스트 케이스를 만든다.
- **학파 차이**: 해석과 길흉은 학파마다 다르다. "이 앱의 기준"임을 밝힌다.
- **개인정보**: 생년월일시는 민감한 개인정보가 될 수 있다. 서버 저장을 피하거나 최소화하고, 저장 시 보관 기간과 목적을 고지한다.
- **면책**: 운세는 오락/참고용. 의료, 법률, 투자 판단을 대체하지 않는다는 문구를 넣는다.
- **저작권**: 시중 운세 책, 사이트 문구를 그대로 복사하지 않는다. 직접 작성하거나 AI로 생성 후 검수한다.
- **취약 사용자**: 불안을 키우는 표현(재앙, 죽음 등)을 피하고, 부정적 결과도 행동 조언으로 마무리한다.
