## 결정 기록

- 2026-11-24: 카카오 JS SDK는 쓰지 않는다. 사용자 질문으로 방향을 바꿨다. 앱 키·도메인 등록 없이 Web Share API(`navigator.share`)로 OS 공유창을 띄우고, 거기서 카카오톡 등을 고르게 한다.
- 2026-11-24: 방향은 링크 공유 + 결과 화면 캡쳐 이미지 공유. PC는 Web Share 지원이 약하므로 링크 복사와 이미지 저장으로 대체한다(안, 리서치 후 확정).
- 리서치 범위: Web Share API 지원 범위(모바일·PC·인앱 브라우저), 파일 공유 가능 여부, 캡쳐 라이브러리와 라이선스, PC 대체 방식.
- 2026-11-24: 리서치 완료. 기존 `src/hooks/use-capture.hook.ts`(html-to-image + navigator.share 파일 공유 + downloadjs)가 이미 있고 로또 `number-list.component.tsx`에서 쓴다. 사용자 결정: 이 훅을 활용해 공통 공유 기능으로 확장한다. 카카오 Android 인앱은 navigator.share·클립보드가 막혀 안내가 필요하다.
- 2026-11-24: 기획 승인. 1차 범위는 뭐 먹지, 운빨 뽑기 3종, 궁합. 공유 카드는 공유용 고정 폭으로 따로 만든다(Q21). 이름이 실리는 카드는 공유 직전 미리보기(Q22). 나머지 열린 질문은 권장안. 실기기 대상 버전(Q7)은 QA 전에 PM이 정한다.
- 2026-11-24: 설계 승인. D-6은 1차에서 OG 이미지 하단 로또 문구를 수정한다. D-2는 공통 문구는 공용 상수, 카드 문구는 기능별 파일. 나머지는 권장안.
