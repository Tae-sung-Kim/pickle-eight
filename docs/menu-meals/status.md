## 확정 결정

- 끼니: 점심 / 저녁 / 아침·브런치. 술안주·야식 끼니는 만들지 않는다(야식은 저녁의 카테고리)
- 주소 `/meal`, `/lunch/today`와 `/lunch`는 301로 이동, sitemap에서 옛 주소 제외
- 폴더 `features/lunch` → `features/meal`, 메뉴 그룹 키·색 토큰 `meal`/`menu-meal`
- 금지어 "든든한" → `든든`, 기존 점심운 한 줄 교체
- 저녁·아침 메뉴 추가와 검수는 PM이 했다
- 점심 목록 조정(사용자 결정 C): 치킨·튀김·깐풍기·마라샹궈 제외, 비빔국수 추가, 이후 12개 메뉴 추가와 쌈밥 한식 이동으로 점심 54개
- 저녁 "야식" 카테고리(사용자 결정): 끼니는 셋 그대로, 저녁에만 7번째 카테고리를 기본 꺼짐으로 추가. 안주 연상 메뉴를 야식 카테고리로 모음. 저녁 106개(야식 40, 이름이 겹쳐도 됨), 아침·브런치 44개. 야식은 단독 선택(켜면 다른 칩이 꺼지고 반대도 같음). 칩을 전부 끄면 기본 후보 전체(저녁은 야식 제외 66개)에서 뽑는다. 안주 연상 제외 기준은 아침·브런치에만 적용. 화면·문구에 술·안주·해장 표현 없음, 라벨 "야식"만 금지어 예외
- 칩 격자: 640px 이상 4열, 모바일 2열, 마지막 홀수 칩 같은 폭·왼쪽 정렬
- 지도 링크 3개(구글 포함) 사용자 승인 확인

## 개발 중 발견

- 돌림판 svg 좌표가 서버와 브라우저에서 부동소수점 끝자리까지 달라 hydration 불일치가 났다(점심 45칸에서 드러남). `roulette.component.tsx`에서 좌표를 `toFixed(3)`으로 반올림해 해결.
- 지도 링크가 데스크톱에서 가로로 놓이던 것, 모바일에서 돌림판이 가로 스크롤을 만들던 것은 QA에서 잡아 수정.
