# 점심 추천 문구 작성·검수 이력

이 문서는 점심운, 고지, FAQ 문구의 작성자, 작성일, 검수 상태를 기록한다. 형식은 `docs/dream/copy-log.md`, `docs/tarot/copy-log.md`를 따른다. 작성 이력은 문구 데이터에 넣지 않고 이 문서에만 둔다.

## 작성 원칙

- 외부 문장 미참조: 다른 사이트의 풀이, 메뉴 소개, 서비스 문구를 보지 않는다. 설계서(`design.md` 3.4, 7장)와 `ui-ux-design.md` 문구 표만 근거로 쓴다. 웹 검색으로 문장을 찾지 않는다.
- 점심운: 합니다체, 한 문장, 가벼운 가능성 표현("~일 수 있습니다", "~어떨까요"). 메뉴 이름, 국물, 맛, 건강, 영양, 효능을 말하지 않는다. 예언·보장·순위·가게 추천처럼 읽히는 표현을 쓰지 않는다.
- 금지 표현: `src/features/lunch/constants/lunch-copy-rule.constant.ts`(검사 전용).
- FAQ 답에는 "보장"을 쓰지 않는다. 상시 고지 문장만 예외다.
- 순서: 샘플 6줄 → 사용자 검수(CP-2) → 나머지 18줄(T-07) → 최종.

## 한계

- 현재(2026-11-19) 웹 검색 유사도 점검은 하지 않았다. 샘플은 외부 문장 참조 없이 처음부터 작성했다.
