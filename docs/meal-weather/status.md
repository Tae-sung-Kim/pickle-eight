## 결정 기록

- 2026-11-28: 날씨 출처는 기상청 동네예보(공공데이터포털). 광고가 있는 사이트라 Open-Meteo 무료판은 쓰지 않는다.
- 2026-11-28: 위치는 시·도 선택(좌표 권한 없음). 개수는 현행 행정구역에 맞추고 개발 단계에서 격자 좌표를 대조한다.
- 2026-11-28: 날씨 분류 우선순위 눈 → 비 → 더움(28°C 이상) → 추움(5°C 이하) → 보통. 임계값은 상수 한 곳.
- 2026-11-28: 추천은 어울리는 메뉴의 확률 가중치만 높인다. on/off 스위치 기본 켜짐. 호출 실패 시 날씨 없이 기존 추천.
- 2026-11-28: 날씨 태그는 기존 메뉴에 붙이고, 후보가 5개 미만인 날씨만 아침·점심·저녁별로 메뉴를 보충한다.
- 2026-11-28: 1차 범위는 뭐 먹지만. 운세 등 다른 메뉴 연결은 반응을 보고 나중에 검토한다.
- 2026-11-28: `DATA_GO_KR_API_KEY`를 서버 런타임에서 쓴다. README 표와 COMPLIANCE.md를 함께 고친다.
- 2026-11-28: 설계 DQ1 서버 메모리 Map 캐시(성공만), DQ2 02시 발표 1회, DQ3 가중치 3, DQ4 날씨 자료를 썼으면 보통 날씨에도 출처·정확도 문구 표시. 모두 권장안, 사용자 부재 중 확정이라 복귀 후 재확인.
- 2026-11-28: 개인 도메인은 나중에 별도로 진행한다.
- 2026-11-28: 출처 주소는 `https://www.weather.go.kr/w/index.do`. 작성연도는 확인 전이라 문구에서 뺀다(출시 전 사용자가 공공누리 요건·연도 확인, 출시 차단 항목).
- 2026-11-28: 태그 기준표(`weather-tags.md`) 승인: 아침 비 칸에 칼국수·김치전 보충, 보충 기준은 끼니×날씨 칸, 야식은 태그 없음, 가중치 3 확정(DQ3).
- 2026-11-28: 격자 값은 공식 변환식 산출 임시값(grid-check.md 9장). 발표 시각 여유값은 예보 02:20, 실황 45분(상수). 전남·광주는 한 지역, 대표 지점 광주시청.
- 2026-11-28: **출시 차단 항목**: (1) 격자 공식 파일 대조, (2) 공공누리 작성연도·요건 확인, (3) 약관 제14조 5항 원문 대조, (4) 서비스키 실호출 1회 확인(Decoding 키), (5) 방침·약관 문구와 시행일(EFFECTIVE_DATE) 최종 승인, (6) 운영 환경 `DATA_GO_KR_API_KEY` 설정과 활용신청(15084084).
- 2026-11-28: 공공데이터포털 15084084 이용허락범위는 "저작자표시(CC BY)"와 "공공저작물 출처표시 제1유형"이며 작성연도·작성자명 요구는 화면에 없다. 엔드포인트(`VilageFcstInfoService_2.0`)와 호출(getVilageFcst, getUltraSrtNcst)은 코드와 일치한다. 출시 차단 항목 (2)는 "작성연도 확인"에서 "출처 표시 문구 최종 확인(법적 판단 아님)"으로 낮춘다.
- 2026-11-28: 서비스키 실호출은 단기·실황·중기 모두 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR`(코드 30). 활용신청 승인 여부와 키 일치 확인 대기(출시 차단 항목 4·6).
- 2026-11-28: 서비스키 등록 확인. 단기예보·초단기실황 실호출 200, 응답 모양이 변환 코드 가정과 일치(PTY·SNO·TMX·TMN, SNO "적설없음"). Decoding 키 + URLSearchParams 방식 확인. `/api/meal/weather` 서울 cold, 부산 normal, 제주 rain 확인(출시 차단 항목 4 해결). 1회 호출 944행으로 numOfRows 1000에 여유가 작다.
- 2026-11-28: 남은 출시 차단 항목: (1) 격자 공식 파일 대조, (3) 약관 제14조 5항 원문 대조, (5) 방침·약관 문구·시행일 최종 승인, (6) 운영 환경 키 설정과 운영 전환. (2) 출처 문구 최종 확인(법적 판단 아님).
