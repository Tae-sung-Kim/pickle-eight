## 1. 기상청 홈페이지 주소

- 문제: plan·dev-tasks의 AC-10은 `MEAL_WEATHER_SOURCE_URL`이 `https://`로 시작하기를 요구한다. 기관 페이지 표기(`http://`)는 이 조건과 맞지 않는다.

  - 출처: https://www.fairdata.go.kr/ext/data/openApiGuidance.do (확인 2026-11-28)

### 3-2. 운영 전환 절차 (포털 안내, 검색 요약 포함)

1. 개발계정으로 API 활용신청. 승인 방식은 API마다 다르다. 자동승인이면 신청과 동시에 쓴다. 승인심의이면 담당자 확인 후 쓴다.
2. 개발과 테스트를 마친다.
3. 마이페이지의 API 활용현황 > API 활용내역 상세 화면에서 운영계정을 신청한다. 필요한 트래픽을 적고, 활용사례(앱 설명과 화면 자료)를 등록한다.
4. 운영계정은 심의를 거친다. 승인심의는 2~3일 걸리고 결과는 가입 시 이메일로 온다(검색 요약).
5. 운영계정 일 한도: 포털 일반 안내는 "하루 최대 10만 건"으로 설명한다. 15084084 개별 운영 한도는 미확인.

## 4. 공공데이터 이용약관 제14조 5항

- 확인 URL: https://www.data.go.kr/ugs/selectPortalPolicyView.do (확인 2026-11-28, 요약 도구로 조회. 원문 글자 단위 대조는 못 했다.)
- 제14조의 제목은 "제공기관"이다. 제3장 "권리·의무 및 책임"(제12~14조)에 있다. 제14조는 1항부터 5항까지 있다.
- 4항(요지): 제공기관은 다음 경우 공공데이터 제공을 중단할 수 있다.
  1) 공표된 이용요건을 위반해 기관 업무에 상당한 지장이 우려되는 경우
  2) 제3자의 권리를 현저히 침해하는 경우
  3) 범죄 등 불법행위에 악용하는 경우
  4) 목록 제외를 행정안전부장관에 요청한 경우
  5) 분쟁조정위원회가 정한 그 밖의 경우
- 5항(요지): 오픈 API로 제공되는 데이터에 관해, 특정 회원의 이용 형태가 제공기관 업무에 지장을 주거나 제공 시스템 성능을 떨어뜨리면 서비스 이용을 제한할 수 있다.
- 광고 사이트에 주는 영향:
  - 5항 본문에서 광고 게재나 상업 이용을 직접 금지하는 문구는 찾지 못했다.
  - 실제 영향은 호출이 많이 몰려 이용이 제한될 수 있다는 점이다. 캐시로 호출 수를 줄이는 근거가 된다.
  - 4항 1)은 "공표된 이용요건" 위반이 전제다. 공표된 이용요건에 광고나 상업 이용 관련 금지 문구가 있는지는 미확인. 15084084 상세 페이지의 이용 요건 전문을 확인해야 한다.
- 출시 전 조치: PM이 약관 원문을 열어 5항 번호와 문구를 한 번 대조한다.

## 5. 서비스키 인코딩 (Encoding / Decoding)

- 포털 공식 안내: 15084084 페이지에는 Encoding 키와 Decoding 키를 구분하는 안내가 없었다(확인 2026-11-28). 공식 FAQ는 확인하지 못했다. 공식 확인: 미확인.
- 커뮤니티 사례(2차 자료, 공식 아님):
  - Encoding 키는 이미 퍼센트 인코딩된 값이다. URL 문자열을 직접 이어 붙일 때 쓴다.
  - Decoding 키는 원문 값이다. 값을 자동으로 인코딩해 주는 라이브러리의 파라미터 기능에 넣는다.
  - Encoding 키를 자동 인코딩 기능에 넣으면 이중 인코딩이 되어 인증 오류가 난다는 사례가 여러 건 있다.
  - 디코딩한 키가 로그에 남아 마스킹이 안 되는 문제도 보고되었다. 키는 로그에 남기지 않는다.
- 사례 출처:
  - https://github.com/jonghee1998/Quant-Auto-Trade/pull/24
  - https://github.com/polopy07/jeonse_companion/pull/74
  - https://github.com/S-DUNG/Ongil-Server/pull/5
- 이 앱 적용 여부: `URLSearchParams`는 값을 자동으로 인코딩한다. 사례 기준으로는 Decoding 키를 넣는 쪽이 맞다. 다만 실제 호출 1회로 확인하기 전에는 확정하지 않는다. 확인 필요.
