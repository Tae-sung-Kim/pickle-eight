# 개인정보처리방침·이용약관·동의 문구 검토

작성 기준: 현재 코드 상태(시행일 2026-11-25 표기). 이 문서는 검토 목록이며 본문은 수정하지 않았다. 법적 문구 수정은 사용자 승인 후에만 진행한다. 법률 해석이 필요한 항목은 "검토"로 표시했고, 최종 판단은 법률 검토 대상이다.

## 처리 현황

사용자 결정("판단에 맡김", 변호사 없음)에 따라 사실에 맞는 최소·보수적 문구로 정리했다. 시행일은 2026-11-26으로 유지한다.

- 수정됨
  - 넛지 "월 서버비 약 5만 원 · 이용자 1,000+" 수치 삭제.
  - 보호책임자를 "운빨연구소 운영자 (연락처: contact.tskim@gmail.com)"로 표기. 문의처 공개 유지.
  - 방침·약관 변경 공지: 시행일과 함께 문서 상단 공지, 불리하거나 중요한 변경은 시행 30일 전. 코드에 별도 공지 수단이 없어 홈 공지는 쓰지 않았다.
  - 약관 관할: "민사소송법에 따른 관할 법원".
  - 방침·약관 끝의 "[알림] 법률 자문이 아닙니다" 블록 삭제.
  - 국외 이전: Vercel Inc., Supabase Inc. 목록으로 정리. 국가는 "미국 등"(리전은 README와 코드에서 확인하지 못함).
  - 약관 책임 제한: 고의 또는 중대한 과실 예외 추가.
  - 서버 로그: 호스팅 사업자(Vercel) 정책에 따른 보관으로 수정. 5장에도 한 줄 추가.
  - 방문 통계: "쿠키를 사용하지 않는 방식으로 집계합니다(Vercel Web Analytics)".
  - 동행복권 수집 문구: "공개된 결과 데이터를 합리적인 호출 빈도로 수집"으로 완화. `COMPLIANCE.md` 3장은 상류 약관 검토를 "주기적으로 할 일"로만 적고 있어 확인 근거가 아니다.
  - 닫기(×): 코드상 닫기는 배너만 숨기며 상태는 미선택으로 남아 광고 스크립트를 불러오지 않고 다음 방문에 배너가 다시 뜬다. aria-label과 방침 7장을 이에 맞췄다.
- 유지
  - 약관 "외부 데이터를 사용하지 않습니다": `src/features/meal`에 외부 요청 코드가 없고 메뉴 목록이 상수라 맞다고 판단.
  - 문의처 Gmail.
- 보류(확인 못 함)
  - 약관·방침 "만 19세 미만 복권 구매 금지": 문구는 `COMPLIANCE.md` 2장의 연령 확인 구현과 맞지만 근거 법령은 문서에서 찾지 못했다.
  - Vercel Web Analytics 쿠키 미사용 여부, Vercel·Supabase 서버 리전, 카카오 애드핏 처리 국가: 코드와 문서에 근거 없음. 단정하지 않았다.
  - 이 문서 아래 표의 나머지 항목(2번 절 표 개편, 넛지 거부 선택지 등).
