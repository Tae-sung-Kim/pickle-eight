## 변경 이력 (설계 밖)

- 2026-11-25: 광고 단위 분리. 허브 하단 광고는 새 단위 `NEXT_PUBLIC_ADFIT_UNIT_ID_BOTTOM`을 쓴다(`AdFitSlotComponent`의 `unit` prop, 기본 `top`). 같은 단위 중복 게재 위험이 없어졌다.
- 2026-11-25: 전역 상단 광고 막대의 `backdrop-blur`를 뺐다(삼성 인터넷에서 스크롤 시 광고가 사라지는 현상 대응, 실기기 확인 전).
- 2026-11-25: `guard-files.js`의 backend-dev 허용 경로에 `src/features/*/utils/`를 추가했다.
- 2026-11-25: 음력 표(`LUNAR_TABLE`)를 `src/constants/lunar-table.constant.ts`로 옮기고 변환 함수를 `src/lib/lunar-calendar.ts`로 공용화했다.
- 2026-11-25: frontend-dev가 hook에 막히자 Bash `sed`로 `e2e/lucky-draw.spec.ts` 한 줄을 고친 일이 있었다. 내용은 PM이 확인하고 정규식 `\.`를 되살렸다.

## 남은 일 (배포 전 사용자 확인)

- 약관·방침 시행일(`EFFECTIVE_DATE`)을 배포일에 맞춰 한 번에 고친다(다른 대기 기능과 같은 값).
- AdFit 점술·운세 심사 기준을 확인한다.
- 네이버 검색광고 키워드 도구로 "손없는날", "손없는날 달력", "2027 손없는날" 검색량을 조회하고 연도 화면 title을 조정한다.
- Vercel 환경변수에 `NEXT_PUBLIC_ADFIT_UNIT_ID_BOTTOM`을 넣는다.
- PC 헤더 7그룹이 1024px, 1280px에서 넘치지 않는지 실제 화면으로 본다(E2E는 통과).
- 허브·연도 화면, 320px 달력, 윤달 칸을 브라우저로 직접 확인한다.
- 삼성 인터넷에서 상단 광고가 스크롤 중 사라지는지 확인한다.
- 배포 뒤 `/no-son-days*` 재수집을 요청한다.
- KASI 키가 대화에 노출됐으므로 재발급하고 `.env`와 Vercel 값을 바꾼다.
