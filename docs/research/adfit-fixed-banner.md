# 애드핏 고정 배너 조사

## 한 줄 요약

카카오 애드핏(AdFit)의 고정 배너(화면 상단·하단에 붙어 스크롤해도 따라오는 광고)를 직접 금지하거나 허용하는 조항은 찾지 못했다. 대신 "배치 공간은 고정되어야 함", "콘텐츠를 가리는 위치 금지", "닫기 버튼을 가리는 배치 금지" 같은 일반 원칙이 있어 간접적으로 적용된다. 따라서 도입 전에 담당 채널로 확인이 필요하다.

## 확인 범위와 주의

- 애드핏 운영정책 원문은 웹 페이지를 가져와 요약 모델을 거친 결과다. 조항 번호와 취지는 맞지만 문구는 원문과 다를 수 있으니 도입 전에 원문을 직접 대조한다.
- 웹 검색 결과에서 나온 블로그 글은 대부분 5~6년 전 글이라 현행 정책의 근거로 쓰지 않는다.
- 삼성 개발자 포럼 글과 삼성 인터넷 17.0 공식 블로그는 조회가 되지 않아(404, 403) 검색 결과 요약만 근거로 했다.

---

## 1. 고정 배너 허용 여부와 제한 문구

### 1-1. 직접 규정은 없음

- 운영정책 5.3.1에 "고정·플로팅"이라는 용어를 직접 쓰는 조항은 없다. 확인 못 함은 아니고, 용어 자체가 없다는 확인이다.
- 가장 가까운 조항은 5.3.1의 배치 원칙이다.
  - 광고가 배치되는 공간은 고정되어야 한다. 고정되지 않은 배치로 방문자가 의도하지 않은 클릭을 하지 않도록 해야 한다.
  - 실수로 클릭하기 쉬운 버튼이나 객체 가까이에 광고를 두지 않는다.
  - 광고 닫기 버튼이 광고 영역 안에 있는 배치를 금지한다.
  - 콘텐츠를 덮거나 가리는 영역에 광고를 두지 않는다.
  - 광고 클릭 없이는 페이지를 이동할 수 없는 위치를 금지한다.
  - 콘텐츠 자체가 오클릭을 부르기 쉬운 위치를 금지한다. 어린이 대상 매체도 포함된다.
- 5.2 콘텐츠 가이드라인에는 레이아웃과 사용성이 크게 떨어지는 경우 제한된다는 내용과, 한 페이지에 광고를 4개를 넘게 두지 않는다는 기준이 있다.

### 1-2. 해석 (확인 필요)

- "배치 공간은 고정되어야 함"을 "화면에 붙어 따라오는 광고"를 금지하는 뜻으로 볼지, "광고 자리가 흔들리지 않아야 함"으로 볼지 문구만으로는 확정할 수 없다. 확인 필요.
- 상단·하단에 고정하면서 본문을 가리지 않으면 5.3.1의 가림 조항은 피할 수 있다. 다만 하단 고정 배너가 탭바나 버튼 근처에 오면 오클릭 조항에 걸릴 수 있다. 확인 필요.
- 블로그 글 중에는 애드핏이 과거에 플로팅 배너를 금지했다가 금지 목록에서 빠졌다는 주장이 있다. 근거가 블로그뿐이라 확인 못 함.

### 1-3. 심사·위반 처리

- 5.4는 팝업 페이지, iframe, 리다이렉트 사이트에서 광고를 호출하는 경우와, 의도하지 않은 시점에 광고가 뜨는 경우를 이용제한 사유로 든다. 광고가 로드 직후나 지연 로드로 뜨는 것도 여기에 해당할 수 있다. 확인 필요.
- 7.1에 따르면 위반 시 경고와 함께 심사 보류가 되고 광고 노출이 중단된다. 수정 기한은 웹사이트 2주, 모바일 앱 4주다.
- 정책 시행일은 2026년 9월 2일로 적혀 있다.

### 1-4. 비교 참고 (Google)

Google Ad Manager의 고정 광고 가이드는 고정 광고에 대해 다음을 요구한다. 애드핏 정책이 아니므로 참고만 한다.
- 가로형 고정 광고는 화면 위나 아래 가장자리에만 붙는다.
- 광고가 스크롤 중에 나타나거나 사라지면 안 된다. 스크롤에 따라 들어오고 나가야 한다.
- 콘텐츠, 스크롤바, 다른 광고와 너무 가까우면 안 된다.
- 스크롤 중 떨림이나 지연이 없어야 한다.

## 2. 노출수 집계 기준과 수익 영향

### 2-1. 집계 기준 (카카오 고객센터)

- 노출수는 매체에 광고가 실제로 노출된 횟수다.
- 1회로 집계되는 조건은 둘 중 하나다.
  - 광고의 50% 이상이 사용자에게 보일 때
  - 게재 지면에 1초 이상 노출될 때
- 고객센터 도움말은 고정 배치와 스크롤 배치를 구분하지 않는다.
- "1초 이상 연속"인지, 영상 광고 기준이 따로 있는지는 확인 못 함.
- 같은 광고가 새로고침이나 자동 교체로 여러 번 집계되는지는 확인 못 함.
- 참고로 IAB 뷰어빌리티 표준은 픽셀 50% 이상이 1초 이상 보이면 뷰어블로 본다. 애드핏 기준과 비슷하지만 같은 것은 아니다.

### 2-2. 수익에 미치는 영향

- 고정 배너는 스크롤 중에도 계속 화면에 있으므로, 1초 기준을 쉽게 넘긴다. 따라서 페이지당 노출수가 늘어날 가능성이 높다. 다만 정확한 증가폭은 실측이 필요하다. 확인 못 함.
- 노출이 늘어나도 단가(CPM)가 같다고 보장되지 않는다. 단가 변화는 확인 못 함.
- 정책 5.4는 방문자 현황에 비해 노출·클릭이 비정상적으로 많으면 제한 사유가 된다고 한다. 고정 배너로 노출을 억지로 늘리면 이 조항에 걸릴 수 있다. 확인 필요.
- 노출·클릭을 인위적으로 늘리는 수단은 금지다. 고정 배너 자체는 이 금지 대상이 아니지만, 사용자가 일부러 광고를 보게 만드는 장치는 피해야 한다.
- 정산은 성과 발생 후 1일 뒤 예상 적립금으로 누적된다는 기준이 있다.

## 3. 삼성 인터넷에서 iframe·고정 광고가 사라지는 문제

### 3-1. 알려진 버그 여부

- 삼성 인터넷에서 스크롤 후 애드핏 iframe 광고가 사라지고 복구되지 않는다는 공개 이슈는 찾지 못했다. 확인 못 함.
- 삼성 개발자 포럼에서 찾은 글은 v27 scroll-snap 버그로, 이 문제와 직접 관련이 없다. 해당 글은 조회가 404였다.
- Safari에서 iframe 안의 position: fixed 요소가 탭 복귀 후 페이지 상단에 숨겨지는 버그 보고가 있다. 브라우저가 다르므로 참고만 한다.

### 3-2. 삼성 특허 (참고)

- 삼성 인터넷 관련 특허 출원 글은 팝업형 광고를 목록 없이 행동으로 판별하는 방식을 설명한다. 판별 기준에는 프레임이 스크롤에 맞춰 고정되는지, 프레임 도메인이 페이지와 다른지가 들어간다.
- 숨기는 방법은 프레임 크기를 0으로 하거나 화면 밖으로 밀어내는 방식이다.
- 이는 특허 출원일 뿐 실제 출시 기능인지 확인 못 함. 다만 "다른 도메인의 고정형 iframe이 스크롤에 따라 사라지는" 증상과 일치하므로 점검 가치가 있다.

### 3-3. 우회 방법 (검토 대상)

- 고정 배치를 CSS position: fixed로 주는 대신, 광고를 감싸는 래퍼만 고정하고 광고 스크립트는 건드리지 않는 방식이 블로그에서 권장된다. 블로그 글이라 근거는 약하다.
- 스크립트를 수정하거나 광고 단위 정보를 바꾸면 광고 요청이 실패하거나 무효로 처리될 수 있다. 애드핏 웹 가이드도 생성된 코드를 그대로 넣으라고 안내한다.
- 주소창 접힘에 따른 뷰포트 변화는 모바일에서 흔하다. 100vh는 주소창이 숨겨진 최대 높이를 기준으로 계산되어 첫 로드 때 하단이 잘리거나 스크롤 중 레이아웃이 튈 수 있다.
  - 전체 화면 레이아웃에는 100dvh나 100svh를 쓴다.
  - 하단 고정 바는 뷰포트 단위를 쓰지 않고 bottom: 0을 쓰되, 노치 기기에는 env(safe-area-inset-bottom)을 더한다.
  - 필요하면 visualViewport 값을 CSS 변수로 옮기는 JS 보완을 쓴다.
- Apple 포럼에는 iOS 26 Safari와 WebView에서 하단 주소창이 숨겨질 때 bottom: 0 고정 요소가 잘못 그려지는 보고가 있다. 확인 필요.
- sticky는 부모 요소 안에서만 고정되므로 화면 전체에 붙이는 용도로는 맞지 않는다. 화면 고정은 fixed나 그에 준하는 방식이 필요하다.

### 3-4. 실측 권장

- 광고 차단 기능과 확장 기능을 끈 상태에서 삼성 인터넷과 크롬을 같은 기기에서 비교한다.
- 광고가 같은 도메인 iframe인지, 다른 도메인인지에 따라 결과가 달라지는지 확인한다.
- 주소창 접힘 전후로 광고 위치가 변하는지 확인한다.

## 4. 삼성 인터넷의 광고 차단·추적 방지 기본값

- 광고 차단(Ad blocker)은 기본으로 꺼져 있다. 사용자가 메뉴에서 광고 차단 확장을 직접 설치해야 켜진다. 삼성 개인정보 설정 마법사는 드물게 사이트가 깨질 수 있다고 안내한다.
- 스마트 추적 방지(Smart Anti-tracking)는 삼성 인터넷 17.0부터 미국, 한국, 유럽 등 일부 지역에서 기본으로 켜진다. 새로 설치하면 "항상"으로 설정된다. 업그레이드 설치는 사용자가 바꾼 적이 없으면 같은 값이 적용된다. 이전 버전은 기본 꺼짐이었다.
- 추적 차단 기능(Tracking Blocker, 디스컨넥트 기반)은 6.2 버전에서 비밀 모드에서만 기본 켜짐이었다. 현재 상태는 확인 못 함.
- 스마트 추적 방지가 애드핏 광고를 막는지는 확인 못 함. 교차 사이트 추적 쿠키나 스크립트를 막는 방식이라 광고 로드에 영향이 있을 수 있다.
- 기본 설정이 최신 버전과 지역에서도 같은지는 확인 필요.

## 5. 기획자에게 넘길 열린 질문

1. 애드핏 담당 채널에 "화면 상단·하단 고정 배너"를 문의해 허용 여부를 서면으로 받을 것인가. 이 문서의 1장 해석은 확정이 아니다.
2. 고정 배너를 하단에만 둘지, 상단에도 둘지. 하단은 오클릭 위험이 있다.
3. 고정 배너가 본문을 가리지 않도록 본문 하단 여백을 어떻게 잡을지.
4. 고정 배너의 노출 증가를 수익 목표에 넣을지. 노출수 증가 시 비정상 트래픽 판정 위험을 어떻게 볼지.
5. 삼성 인터넷 실측 결과가 나오기 전에 고정 배너를 출시할지, 아니면 실측 후로 미룰지.
6. 광고 차단 기본값은 지역과 버전에 따라 다르므로, 광고 미노출 구간을 얼마나 허용할지.
