# 궁합 테스트 리서치

작성일: 2026-11-24
작성: researcher
용도: planner가 궁합 테스트 `docs/compatibility/plan.md`를 쓸 때 입력으로 쓴다.
범위: 궁합 종류별 규칙과 해석 방식, 이름 궁합 포함 판단 자료, 검색 수요와 경쟁 사이트 구성, 저작권, 개인정보·법적 고지, 추천 범위. 기술 구현 방식은 쓰지 않는다.

표시 규칙
- "공식 규칙"은 법령이나 공인 기관이 정한 규칙이다. 궁합에는 공식 규칙이 없다.
- "전통 이론"은 명리학, 점성술 등 오래된 학문·문화에서 전해지는 규칙이다. 과학적 검증은 되지 않았다.
- "관례"는 학파나 사이트들이 공통으로 쓰는 방식이다. 출처마다 다를 수 있다.
- "확인 필요"는 이번 조사에서 근거를 확보하지 못한 항목이다.
- "법률 확인 필요"는 상업 서비스에 쓰기 전에 전문가 확인을 권하는 항목이다.
- "검색 요약 기준"은 원문 페이지를 열어 확인하지 못하고 검색 결과 요약만 본 항목이다.
- 이 문서는 법률 자문이 아니다. 경쟁 사이트의 문장과 표는 복사하지 않고 규칙만 사실로 정리했다.

### 0.3 코드 검산 메모

- 띠 계산식은 연도 기준이다. 입춘 이전 출생이면 전년도 띠가 된다는 정책은 기존 운세와 같은 기준을 써야 두 기능의 결과가 어긋나지 않는다.

## 1. 한 줄 요약

궁합은 두 사람의 정보(띠, 별자리, 혈액형, 이름, 생년월일 등)를 정해진 규칙으로 맞춰 보고, 잘 맞는 정도나 관계의 특징을 재미로 보여 주는 콘텐츠다. 과학적 근거가 확인된 것은 거의 없고, 한국에서는 무료 웹 테스트가 주된 소비 방식이다. 서비스는 "오락용"임을 밝히고 연애·결혼·이별을 단정하지 않아야 한다.

## 2. 기존 띠별·별자리 운세와 무엇이 다른가

사용자가 "띠·별자리는 이미 있지 않냐"고 물었다. 두 기능은 입력과 결과 단위가 다르다.

| 구분 | 띠별·별자리 운세 (기존) | 궁합 (신규) |
|---|---|---|
| 입력 | 본인의 띠 또는 별자리 하나 | 두 사람 각각의 띠·별자리(또는 다른 항목) |
| 결과 단위 | 한 사람이 속한 집단의 오늘 운세 | 두 사람의 조합(관계) |
| 결과가 바뀌는 조건 | 날짜(매일 바뀜) | 조합 자체. 날짜가 바뀌어도 같은 조합이면 같은 결과가 자연스럽다 |
| 데이터 규모 | 12 항목 × 날짜별 문구 | 12띠 기준 78개 조합(순서 없는 쌍, 같은 띠 포함), 별자리 기준 78개 조합 |
| 해석의 대상 | 한 사람의 하루 흐름 | 두 사람 사이의 "잘 맞는 정도", "조심할 점", "잘 맞는 방식" |
| 점수 | 기존 운세는 "점수는 정확도가 아님" 고지가 붙는다 | 점수를 쓰면 상대방과 비교하는 인상이 강해져 표현 위험이 커진다 |
| 필요한 정보 | 띠는 출생 연도, 별자리는 출생 월일 | 같은 정보에 더해 상대방 정보(제3자 정보 이슈, 9장) |
| 개인정보 | 본인 정보 1명 | 타인 정보 포함. 정보주체 동의 확인이 필요할 수 있다(법률 확인 필요) |

핵심 차이를 한 줄로 쓰면 다음과 같다. 띠별 운세는 "나는 어떤 하루인가"를 보여 주고, 궁합은 "나와 너는 어떤 사이인가"를 보여 준다. 따라서 궁합은 날짜가 아니라 두 항목의 조합표를 데이터로 가진다. 기존 띠·별자리 계산 로직은 그대로 재사용할 수 있다.

## 4. 궁합 종류별 규칙과 해석 방식

### 4.0 공통 원칙

- 궁합에는 공식 규칙이 없다. 각 종류는 전통 이론이나 대중 관례이며 서비스마다 점수 방식이 다르다.
- 같은 종류라도 학파와 사이트마다 세부 규칙이 다르다. 서비스가 쓰는 기준을 하나로 정하고 화면에 밝혀야 한다.
- 점수 방식은 사이트가 임의로 정한 것이다. 예를 들어 어떤 사이트는 삼합 100점, 육합 95점, 상충 35점, 원진 20점을 준다. 이는 전통 기준이 아니다(출처: 5.1).

### 4.1 띠 궁합 (지지 관계)

- 분류: 전통 이론(명리학의 지지 관계). 과학적 검증은 없다.
- 계산 규칙: 두 띠의 지지 관계를 찾는다. 우선순위와 점수는 서비스 자체 규칙이다. 두 띠가 같은 띠인 경우(예: 쥐와 쥐)는 별도 문구가 필요하다. 여러 사이트에서 같은 띠끼리의 관계를 따로 설명하는 것이 보인다.
- 해석 문구 방식: 관계 유형별(육합, 삼합, 방합, 충, 원진, 형·파·해)로 짧은 설명을 쓰고, 두 띠 이름을 넣어 개인화한다. 관계 유형이 같은 조합끼리는 설명이 거의 같아지므로, 조합마다 문구를 다르게 쓸지 기획 결정이 필요하다.
- 상충·원진 관계의 표현: "잘 안 맞을 수 있다"보다 "생활 습관에서 부딪힐 수 있다"처럼 행동 조언으로 바꾸는 것이 안전하다(9.4).

### 4.2 별자리 궁합 (원소·양태)

- 분류: 서양 점성술의 대중 관례. 천문 계산(태양 위치)은 맞지만 궁합 해석은 과학적 근거가 없다.
- 계산 규칙(원소, 관례): 같은 원소끼리는 조화롭다고 본다. 불과 공기, 흙과 물처럼 보완된다는 설명도 많다. 불과 물, 공기와 흙처럼 대립한다는 설명도 많다. 출처별로 조합이 조금씩 다르다(5.4).
- 계산 규칙(양태): 확인 필요. 이번 조사에서 양태 분류와 조합 규칙을 설명하는 출처를 확보하지 못했다. 한국어 위키 "삼궁" 문서와 영문 위키 궁합 문서 모두 양태 규칙을 다루지 않았다.
- 해석 문구 방식: 원소 조합(같은 원소, 보완, 대립) 세 가지 유형으로 묶으면 12×12 조합을 세 유형으로 줄일 수 있다. 다만 "같은 원소라서 잘 맞는다"는 문구는 과장되기 쉬우므로 "비슷한 감성을 쓰는 편"처럼 조건을 낮춘다.
- 경계일 처리: 별자리 판정은 절기 시각 기준이다. 경계일 출생자는 시각이 필요하다(기존 판정 함수 재사용). 궁합 결과에도 경계일 안내를 같이 쓸지 결정이 필요하다.

### 4.3 혈액형 궁합

- 분류: 유사과학. 혈액형 성격설은 과학적 근거가 없다는 것이 조사한 출처들의 공통된 결론이다.
- 계산 규칙: 궁합표(혈액형 조합별 점수)가 사이트마다 있다. 그 점수에는 과학적 근거가 없다.
- 연구 결과: 2015년 발표된 일본인 1,427명 대상 연구(PLOS ONE, 원문 PMC4433257)는 ABO 혈액형과 성격 특성 사이에 과학적 합의가 없다고 서술하며, 일부 항목에서 효과 크기가 작은 차이만 보고했다. 2차 출처에 따르면 2008년 대한혈액학회도 이 설을 부정했다(2차 출처, 확인 필요).
- 해석 문구 방식: 사이트들은 "재미로 보는 것"이라는 고지를 붙이며, 성격을 단정하는 문구를 쓴다. 이 방식은 차별 우려가 있다(9.4).
- 판단: 과학적 근거가 없고, 특정 속성으로 사람을 나누는 표현이 되기 쉬우므로 제외를 권장한다(10장).

### 4.4 이름 궁합

- 분류: 두 종류가 섞여 있다.
  - 놀이식 이름 궁합: 두 이름의 글자를 번갈아 배열하고, 한글 획수를 더해 가며 줄여 최종 두 자리 숫자를 퍼센트로 보여 준다. 규칙은 간단하지만 근거가 없다.
  - 성명학식 이름 궁합: 한자 획수로 원·형·이·정 4격을 계산하고 길흉을 풀이한다. 전통 이론을 주장하지만 학술 근거가 약하다.
- 계산 규칙의 불일치:
  - 한글 획수: 자음·모음 획수를 어떻게 셀지 작명소마다 다르다. 예를 들어 "ㄱ"을 1획으로 셀지 꺾이는 곳마다 2획으로 셀지에 따라 결과가 달라진다. 순서(성 먼저인지, 두 이름을 섞는지)에 따라서도 결과가 달라진다.
  - 한자 획수: 원획법(원래 획수)과 파자 획수 등 유파가 나뉜다. 한자 이름은 글자별 획수 표가 있어야 한다.
  - 한글 이름의 한자 변환은 입력 자체를 모호하게 만든다(동음이의 글자 처리).
- 학술 근거: 학위논문 요약에 따르면 성명학은 검증된 바가 없다고 평가되며, 최적의 작명법을 인정할 근거도 부족하다. 획수 이론을 비판하는 성명학자들의 글도 있다(검색 요약 기준).
- 해석 문구 방식: 점수(퍼센트)와 길흉 풀이가 함께 나온다. "좋은 이름/나쁜 이름"처럼 사람을 평가하는 문구가 쓰이기 쉽다.
- 판단: 6장에서 따로 정리한다.

### 4.5 생년월일·사주 궁합

- 분류: 전통 이론(명리학). 학파에 따라 해석이 다르다.
- 계산 규칙(관례 순서): 일간(천간) 관계 → 일지(지지) 합·충 → 두 사주의 오행 분포 → 용신 교류 순으로 본다. 천간합(갑기, 을경, 병신, 정임, 무계)이 있으면 끌림을 말하고, 상생·상극·비화로 일간 관계를 나눈다. 일지 육합은 생활 궁합, 일지 충은 생활 습관에서 부딪힌다는 설명이 붙는다. 여러 사이트가 같은 순서를 쓴다(출처: 5.6).
- 전통 지식의 한계: 일지의 합·충만 보면 일부만 본다는 지적이 있다. 가장 흔한 실수는 합만 찾는 것이다(검색 요약 기준).
- 주의: 남녀 궁합으로 보는 관례가 있어 성별 입력을 요구하는 사이트가 많다. 성별 역할로 궁합을 나누는 것은 차별 우려가 있다(9.4).
- 시간 미상: 태어난 시각을 모르면 사주 기둥이 달라진다. 기존 운세의 "두 가지 결과 모두 확인" 안내를 재사용할 수 있다(기존 문구 `FORTUNE_TIME_UNKNOWN_NOTICE`).
- 해석 문구 방식: 관계 유형(천간합, 일지 합, 충 등)과 오행 분포를 조합해 문장을 만든다. 사주 용어가 많아 일반 사용자에게 어려울 수 있다.

### 4.6 MBTI 궁합

- 분류: 대중 관례. 궁합 조합에 대한 실증 근거는 확인하지 못했다.
- 계산 규칙: 서비스마다 16×16 궁합표를 따로 만든다. 공식 규칙은 없다. 궁합표는 유형 설명을 조합한 추론이며, 실제 커플 추적 데이터가 아니다.
- 근거 관련 정보(검색 요약 기준): 한 글은 메타분석에서 유형 매칭과 관계 만족도의 약한 상관을 언급했지만 출처를 밝히지 않았다. 검사 재검사 신뢰도 문제를 지적하는 글도 있다. 관계를 실제로 예측하는 요인으로는 갈등 회복, 가치관 합의, 정서적 안전감이 꼽힌다(확인 필요).
- 해석 문구 방식: 유형 설명이 모호해 바넘 효과에 취약하다.
- 판단: 검사 도구의 상표·저작권 문제가 있고(5.5), 근거가 약하므로 제외 또는 후순위를 권장한다.

## 6. 이름 궁합 포함 여부 판단 자료

### 6.1 쟁점 정리

| 쟁점 | 내용 | 판단 |
|---|---|---|
| 계산 방식의 불일치 | 한글 획수, 한자 획수, 순서, 이름 배열 방식마다 결과가 달라진다. 하나를 정하면 다른 사이트와 결과가 다르다 | 기획이 정해야 할 항목이 많다 |
| 학술 근거 | 학위논문 요약 기준 검증된 바 없음. 획수 이론 자체를 비판하는 성명학자도 있다 | 점수를 "정확도"처럼 보이게 하면 안 된다 |
| 개인정보 | 이름은 생년월일과 결합하면 개인정보가 된다(서울시 FAQ 기준). 이름 입력은 생년월일보다 식별성이 높다 | 저장하지 않더라도 입력 고지를 강화해야 한다 |
| 아동 이름 | 아이 이름을 입력하는 경우 만 14세 미만 정보를 처리할 수 있다. 부모가 아이 이름을 넣는 상황이 흔하다고 예상되나, 실태 자료는 확인 필요 | 아동 이름 입력을 막는 방법(연령 확인, 안내)이 필요하다. 법률 확인 필요 |
| 차별 우려 | 이름 획수로 길흉을 나누면 이름을 바꾸라는 압박(개명·작명 상품)으로 이어질 수 있다. 특정 글자나 성씨가 불리하다는 식의 설명도 생길 수 있다 | 길흉 판정 대신 재미 중심 표현만 쓰는 방식이 안전하다 |
| 작명 상품 연결 | 작명소 광고와 연결되면 과장 광고 위험이 있다(표시광고법 쟁점은 운세 리서치 8.2와 같다) | 작명·개명 권유 문구를 금지 목록에 넣는다 |
| 광고 정책 | 이름 기반 결과를 광고와 함께 보이는 것은 AdFit 정책 확인이 필요하다(9.6) | 확인 필요 |

### 6.2 포함하는 경우의 최소 조건 (기획 제안)

1. 획수 계산 방식을 하나로 정하고 화면에 밝힌다.
2. 길흉 판정과 "좋은 이름, 나쁜 이름" 표현을 쓰지 않는다.
3. 점수 대신 놀이식 결과(예: 글자 조합의 재미 요소)로 보여 준다.
4. 아동 이름을 입력하지 못하도록 연령 확인을 둔다(법률 확인 필요).
5. 이름 저장과 공유를 하지 않는다.
6. 작명·개명 권유 문구를 쓰지 않는다.

### 6.3 제외하는 경우의 비용

- 이름 궁합은 검색 수요가 큰 키워드다(검색량은 확인 필요. 7장). 제외하면 유입 경로 하나를 잃는다.
- 대신 띠·별자리 궁합에서 같은 "사람 간 궁합" 흐름을 만들 수 있다.

### 6.4 권장

- 1차 출시에서는 제외하고, 기획자가 6.2의 조건을 승인하면 2차 이후 재검토한다.

## 9. 관련 법규·정책

### 9.1 두 사람 정보 입력 (개인정보)

- 생년월일 단독으로는 개인정보가 아니라는 견해가 있으나, 이름 등과 결합하면 개인정보가 된다(개인정보 판단은 결합 가능성에 따름). 서울시 개인정보 FAQ는 개인과 관련된 정보 대부분이 개인정보에 해당할 수 있다고 설명한다(검색 요약 기준).
- 궁합은 상대방 정보를 입력받는다. 입력자와 정보주체가 다르다. 입력자가 상대방 동의를 받았는지 확인할 수 없는 구조다. 이 쟁점은 운세 리서치 8.4와 열린 질문 13번에 있다.
- 서버 저장을 하지 않고 화면 계산만 하면 쟁점이 가벼워진다. 다만 "입력받는 행위" 자체가 처리에 해당하는지는 법률 확인 필요.
- 고지 방향: 입력한 정보가 서버로 보내지지 않는다는 문구(기존 `FORTUNE_PRIVACY_INPUT_NOTICE`와 같은 방식)를 궁합 화면에 쓰고, 상대방 정보를 입력할 때 정보주체의 동의를 받은 뒤 입력하라는 안내를 둘지 기획이 정해야 한다. 이 안내 문장은 새로 작성해야 하며 승인이 필요하다.
- 이름은 식별성이 높다. 이름을 입력받으면 저장과 공유를 피하고, 결과 화면을 캡처해 공유하는 기능을 넣을 때 상대방 이름과 생년월일이 노출되지 않게 해야 한다(공유 기능 우선순위와 연결).

### 9.2 만 14세 미만

- 운세 화면에는 이미 만 14세 이상 대상 안내와 연령 확인 흐름이 있다(기존 `FORTUNE_AGE_INPUT_NOTICE`, `FORTUNE_AGE_BLOCKED_TEXTS`).
- 궁합은 아동 이름이나 아동 생년월일을 입력받을 가능성이 있다. 개인정보보호법 제22조의2(법정대리인 동의) 적용 여부는 운세 리서치 8.4에서 확인 필요로 남았다. 궁합에서는 상대방의 나이를 확인할 방법이 없으므로 쟁점이 더 크다. 법률 확인 필요.

### 9.3 표시광고·과장 표현

- 「표시·광고의 공정화에 관한 법률」 제3조는 소비자를 오인시키는 거짓·과장 광고를 금지한다(조문 1차 확인 필요. 운세 리서치 8.2 인용).
- 궁합 결과를 "정확한 천생연분", "100% 궁합"처럼 표시하면 과장 광고로 볼 여지가 있다. 법률 확인 필요.

### 9.4 단정 표현 (연애·결혼·이별)

- 궁합 점수가 낮으면 "헤어집니다", "이별수", "결혼은 어렵다" 같은 표현이 쓰이기 쉽다. 기존 금지 목록에는 "헤어집니다"가 있다. 궁합 특화 금지어를 추가해야 한다.
- 추가 후보(기획 승인 필요): 결혼·임신·이별·바람·이혼을 예측하는 표현, 특정 사람을 평가하는 표현, "운명의 상대"처럼 확정하는 표현.
- 문장 방향: "이런 점에서 잘 맞는 편입니다", "이런 부분은 서로 조율하면 좋습니다"처럼 가능성과 행동 조언으로 쓴다.

### 9.5 오락 목적 고지

- 한국에서 점술·운세에 오락 고지를 의무화한 법령은 확인하지 못했다(운세 리서치 8.1과 같다). 확인 필요.
- 궁합도 같은 방식으로 "오락과 참고를 위한 콘텐츠이며 관계를 판단하는 근거가 아님"을 밝힌다. 운세 전역 고지(`FORTUNE_DISCLAIMER_TEXT`)를 재사용하고, 궁합 전용 문장을 추가하는 방식을 기획이 정한다.
- 과학적 근거 없음 고지: 혈액형, MBTI 궁합을 넣는다면 이 고지가 특히 필요하다.

### 9.6 광고 플랫폼 정책

- 카카오 AdFit 운영정책은 매체 심사에서 "사행성 / 사금융 관련 콘텐츠"를 게재 부적합 항목으로 둔다. 점술·운세가 이 항목에 해당하는지는 확인하지 못했다(검색 요약 기준).
- 카카오모먼트 제한 업종 가이드에는 운세 서비스가 광고 집행 불가 업종으로 나온다. 다만 이는 광고주 쪽 규정이며, 매체(우리 사이트) 쪽 정책과는 다르다. 확인 필요.
- AdFit 정책은 오해를 줄 수 있는 제목 아래 광고 배치를 금지한다. 궁합 결과 바로 아래 광고 배치가 여기에 걸리지 않는지 확인이 필요하다.
- Google AdSense: 궁합·운세를 제한 항목으로 두지 않는다는 확인은 없다(운세 리서치 8.6과 같다. 확인 필요).
- 미성년 대상 콘텐츠 제한 조항이 AdFit 구판에 있었다(검색 요약 기준). 연애 궁합은 미성년 이용자 대상 여부를 점검해야 한다.
- 결과를 광고로 잠그는 구조(결과 보려면 광고 시청)는 `COMPLIANCE.md` 4장의 방식과 충돌하지 않도록 기획이 정한다.

### 9.7 사이트 내 사용 주의 (기존 규칙)

- 기존 `FORTUNE_FORBIDDEN_TERMS`에는 "사주 분석", "정통", "정확한 맞춤", "AI가", 타 서비스 상표가 있다. 궁합 페이지에도 같은 목록을 적용한다.
- 사주 궁합을 넣으면 "사주" 단어 사용 위치를 기존 화이트리스트(`FORTUNE_SAJU_ALLOWED_TEXTS_METHOD_A`)처럼 관리해야 한다. 궁합용 화이트리스트는 새로 승인받는다.

## 12. 기획자에게 넘길 열린 질문

범위
1. 1차를 띠 궁합과 별자리 궁합으로 확정할지. 사주 궁합을 1차에 넣을지.
2. 이름 궁합을 1차에서 뺄지(권장: 보류), 혈액형과 MBTI를 완전히 제외할지(권장: 제외).
3. 관계 유형(연인, 친구, 동료, 가족)을 고르게 할지. 가족 관계는 민감도가 높아 빼는 것이 나을지.

결과 표현
4. 점수를 보여 줄지(예: 0~100), 등급(잘 맞는 편, 보통, 조심할 편)만 쓸지, 점수 없이 설명만 쓸지.
5. 같은 띠끼리, 같은 별자리끼리 조합의 문구를 어떻게 쓸지.
6. 원진과 해의 정의를 어떤 출처로 고정할지(출처별 차이 있음).
7. 궁합 결과에 행운 요소(색, 숫자)나 로또 연결을 넣을지. 로또 연결은 권장하지 않는다(운세 리서치 9장).

입력과 개인정보
8. 띠 궁합은 연도만, 별자리 궁합은 월일만 받는 최소 입력 원칙을 쓸지.
9. 입력한 정보를 브라우저에 저장할지(권장: 저장 안 함, 기존 운세와 같은 방식).
10. 상대방 정보를 입력할 때 "정보주체 동의" 안내 문장을 둘지, 어떤 문장으로 할지(승인 필요).
11. 14세 미만 이용자가 상대방 정보를 입력하는 경우를 막을지. 법률 확인 필요.
12. 결과 공유 기능을 넣을 때 상대방 정보가 공유 이미지에 나오지 않게 할지.

법적 고지·광고
13. 궁합 전용 면책 문구를 새로 쓸지. 쓴다면 문장 승인 방식.
14. 단정 금지 표현(결혼, 이별, 임신, 이혼 등) 목록을 추가할지.
15. AdFit에서 궁합 결과 페이지에 광고를 게재해도 되는지 확인(매체 정책). 확인 전까지 광고 배치를 보류할지.
16. 미성년 이용자 대상 여부와 연애 궁합 콘텐츠의 연령 제한 방식.

검색·경쟁
17. 키워드 검색량을 네이버 검색광고 도구로 확인해 1차 범위를 조정할지.
18. 차별 포인트를 "관계 유형 설명 중심"으로 잡을지. 이는 기획 가설이며 시장 검증이 필요하다.

데이터 규모
19. 띠 78조합, 별자리 78조합의 문장을 조합형으로 만들지, 조합별로 직접 쓸지. 작성 주체와 검수 방법.
20. 사주 궁합을 2차에 넣는다면 기존 사주 계산 모듈을 재사용할지, 시간 미상 처리를 어떻게 할지.
