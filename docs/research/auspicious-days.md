# 손 없는 날·길일 달력 리서치

작성일: 2026-11-25
작성: researcher
용도: planner가 손 없는 날·길일 달력 기획서 `docs/auspicious-days/plan.md`를 쓸 때 입력으로 쓴다.
범위: 손 없는 날 규칙, 길일 종류와 계산 규칙, 음력·절기 데이터 재사용 여부, 경쟁 서비스와 검색 수요, 저작권·법적 주의, 열린 질문. 기술 구현 방식은 쓰지 않는다.

표시 규칙
- "민속 관례"는 법령이 아니라 민간에서 전해지는 풍습이다. 이 분야에는 공식 규칙이 없다.
- "출처 간 차이"는 조사한 출처끼리 설명이 다른 항목이다.
- "확인 필요"는 이번 조사에서 근거를 확보하지 못했거나 출처가 한 곳뿐인 항목이다.
- "법률 확인 필요"는 상업 서비스에 쓰기 전에 전문가 확인을 권하는 항목이다.
- "요약 검색 기준"은 원문 페이지를 열어 보지 않고 검색 결과 요약만 본 항목이다.
- 이 문서는 법률 자문이 아니다. 경쟁 사이트의 문장과 표는 복사하지 않았고, 규칙과 구성만 정리했다.

### 0.1 데이터 범위의 빈틈
- 음력 표는 2049년까지 있다. 손 없는 날만 필요하면 2049년까지 충분하다.
- 절기 표는 2028년까지만 있다. 월건과 황도·건제를 2029년 이후 날짜에 쓰려면 KASI 절기 데이터를 더 받아야 한다. 운세 기능의 후속 작업 F-1(기한 2028-12-01)과 같은 문제다.
- 운세 기능의 표는 "출생일 범위 1920~2028년"을 위해 만들었다. 달력은 조회 범위가 다르므로 별도 결정이 필요하다.

## 1. 한 줄 요약

손 없는 날은 음력 날짜의 끝자리가 9나 0인 날을 가리키는 민간 풍습이다. 이사, 결혼, 개업 같은 일을 할 날을 고를 때 쓰는 "택일"의 한 방법이다. 황도·흑도, 건제12신, 생기복덕 같은 다른 택일 방식과 함께 쓰이며, 공식 제도가 아니라 민속 관례다.

| 손 없는 날 | 손이 쉬러 하늘로 올라간다고 여겨지는 날. 음력 끝자리가 9 또는 0인 날 | 민속 관례 |

| 황도 | 청룡, 명당, 금궤, 천덕, 옥당, 사명 등 좋은 신이 드는 날 | 황도길일 |
| 흑도 | 백호, 구진, 현무, 천뇌, 천형 등 나쁜 신이 드는 날 | 흑도일은 피하는 관례 |
| 건제12신 | 建·除·滿·平·定·執·破·危·成·收·開·閉 열두 신. 일진과 월건을 비교해 정한다 | 용도별 좋고 나쁨이 있다 |

| 생기복덕 | 일진과 방향·날짜 조합으로 좋고 나쁨을 가리는 방식 (생기, 천의, 복덕 등) | 세부 표는 확인 필요 |
| 혼인총기일 | 결혼에서 피하는 날로 따로 가리는 날 | 결혼 택일 관례 |
| 살부대기월 | 결혼에서 피하는 달로 따로 가리는 달 | 결혼 택일 관례 |
| 띠 충 | 본인의 띠와 맞부딪치는 날. 피하는 관례가 있다 | 개인 정보 필요 |

## 3. 규칙과 관례

### 3.1 손 없는 날 (민속 관례, 공식 규칙 없음)

- 규칙: 음력 날짜의 끝자리가 9 또는 0인 날. 한 달에서 음력 9일, 10일, 19일, 20일, 29일, 30일이 해당하며 최대 6일이다. (여러 출처 일치)
- 양력 날짜는 해마다 달라지므로 음력 달력으로 확인해야 한다. (여러 출처 일치)
- 확인 필요: 음력 29일까지만 있는 작은 달(소월)에는 29일과 30일 중 어느 날이 해당하는지, 출처가 명확히 말하지 않았다. 앱은 음력 달 길이 기준으로 계산해야 하므로 기획에서 정해야 한다.
- 유래(출처 간 차이 있음):
  - 손(損)은 날짜에 따라 동서남북 방위를 돌며 사람의 활동을 방해하는 악귀라고 한다.
  - 음력 끝자리로 손의 위치를 정하는 설명이 있다. 1·2일은 동쪽, 3·4일은 남쪽, 5·6일은 서쪽, 7·8일은 북쪽이며, 9·0일은 손이 하늘로 올라가 쉰다고 한다. 이 설명은 출처 한 곳의 내용이다.
  - 방위를 4방위로 설명하는 출처와 8방위를 돈다고 설명하는 출처가 다르다. 확인 필요.
  - 문헌 근거로 조선 후기 풍속서 《동국세시기》가 거론되지만, 이번 조사에서는 한 블로그 말만 확인했다. 확인 필요.
  - 드라마 제목 등에 쓰인 "무방수날"이라는 옛 표현이 음력 2월 9일을 가리킨다는 설명이 있다(나무위키 요약 기준).
- 현대의 시각: 미신으로 보는 입장도 있고, 중장년층은 이사·결혼·개업 날짜를 정할 때 여전히 중요하게 여긴다는 설명이 있다(출처 요약 기준). 조사 범위에서 통계는 찾지 못했다.

### 3.2 길일 종류와 쓰임

| 종류 | 주로 쓰는 곳 | 계산 기준 | 확신 수준 |
|---|---|---|---|
| 손 없는 날 | 이사 (가장 흔함) | 음력 끝자리 9·0 | 민속 관례, 여러 출처 일치 |
| 황도·흑도 | 이사, 결혼, 개업, 공사 | 월지와 일지 관계로 청룡 시작 일지를 정하고, 열두 신을 순서대로 배열 | 관례. 출처마다 세부 표가 다를 수 있음 |
| 건제12신 | 이사, 결혼, 개업 등 용도별 | 일진과 월건의 관계로 열두 신 중 하나를 정함 | 관례. 용도별 좋고 나쁨은 출처 간 차이 있음 |
| 생기복덕 | 이사, 결혼 등 | 일진과 방위·날짜 조합 | 관례. 세부 표 확인 필요 |
| 결혼 택일 (혼인총기일, 살부대기월, 띠 충 제외) | 결혼 | 피하는 날·달·띠 조합 | 관례 |
| 개인 사주 택일 | 결혼, 개업 등 중요한 일 | 본인 사주와 일진 등을 함께 봄 | 개인 맞춤. 달력 기능과 분리 필요 |

### 3.3 용도별 건제12신 기준 (출처 간 차이 있음)

조사한 두 출처의 기준은 다음과 같다. 같은 용도라도 출처마다 좋은 신이 다를 수 있다.

| 용도 | 좋게 보는 신 | 피하는 신 | 출처 |
|---|---|---|---|
| 이사 | 成, 開, 滿, 平, 定 | 破, 危, 閉 | DayPick 택일 기준 설명 (요약 검색 기준) |
| 결혼 | 定, 成, 開, 滿 | 破, 危, 閉, 執 | 같은 출처 (요약 검색 기준) |

확인 필요: 다른 택일 프로그램은 이사 기준에서 수(收)나 집(執)을 다르게 다룰 수 있다. 개업 기준은 이번 조사에서 확보하지 못했다.

### 3.4 황도·흑도 계산 규칙 (관례)

- 출처 설명(요약 검색 기준)에 따르면 다음 순서로 계산한다.
  1. 월지(월건의 지지)를 기준으로 청룡이 드는 일지를 정한다.
  2. 그 일지부터 열두 신을 순서대로 배열한다.
  3. 배열에서 황도 신(청룡, 명당, 금궤, 천덕, 옥당, 사명)이 드는 날은 황도일(길), 흑도 신(백호, 구진, 현무, 천뇌, 천형 등)이 드는 날은 흑도일(흉)로 본다.
- 주의점으로 두 가지가 강조된다.
  - 월건은 음력 달이 아니라 절기 기준이다. 매월 양력 4~8일 무렵에 월건이 바뀌므로, 음력 달로 택일하면 틀릴 수 있다. 절기 표가 필요한 이유다.
  - 좋은 시간(시각)은 황도일 안에서만 고른다. 흑도일에는 좋은 시간이 나오지 않는다는 설명이다.
- 확인 필요: 흑도 신 목록에 주작을 넣는 출처와 넣지 않는 출처가 있을 수 있다. 대덕황도를 쓰는 곳도 있다고 한다. 앱은 어느 표를 기준으로 할지 정해야 한다.

### 3.5 택일 순서 (관례)

한 출처는 이사·결혼 택일을 다음 순서로 설명한다(요약 검색 기준).
1. 생기복덕 중 좋은 날
2. 황도일
3. 생갑순
4. 월건길신
5. 본인 띠와 충하는 날은 제외

이 순서는 출처마다 다르다. 확인 필요.

### 3.6 오행

- 오행(목·화·토·금·수)이 택일에 어떻게 쓰이는지는 이번 조사에서 근거를 확보하지 못했다. 확인 필요.
- 방위와 오행을 연결하는 설명은 풍수 쪽에서 나오지만 출처 확인이 필요하다.

### 3.7 출처 간 차이 정리

| 항목 | 차이 |
|---|---|
| 손 없는 날 날짜 | 음력 끝자리 9·0이라는 규칙은 일치. 실제 양력 날짜표는 출처마다 다르다 (아래 3.8) |
| 손의 방위 | 4방위 설명과 8방위 순회 설명이 다르다 |
| 건제12신 용도별 기준 | 출처마다 좋은 신과 피하는 신이 다르다 |
| 황도·흑도 신 목록 | 주작 포함 여부, 대덕황도 사용 여부가 다르다 |
| 택일 순서 | 생기복덕, 황도, 월건 등 순서가 출처마다 다르다 |

### 3.8 2026년 11~12월 손 없는 날 날짜 출처 불일치

같은 기간에 대해 출처마다 양력 날짜가 다르게 나왔다. 이는 앱이 직접 계산해 검증해야 한다는 근거다.

| 출처 | 11월 | 12월 |
|---|---|---|
| tess9.com, ajd.co.kr (요약 검색 기준) | 8, 17, 18, 27, 28일 | 7, 8, 17, 18, 27, 28일 |
| lifedestiny.co.kr (요약 검색 기준) | 1, 2, 11, 12, 21, 22일 | 1, 2, 10, 11, 21, 22일 |

- 두 번째 출처는 음력 끝자리 규칙과 맞지 않아 보인다. 조사 과정에서 달력 한 줄을 직접 검산하지 못했으므로 "맞지 않아 보인다"로만 적는다.
- 기획 권장: 음력 표(KASI 기반)로 날짜를 계산하고, 최소 두 출처와 비교한 결과를 검증 기록으로 남긴다.

## 4. 앱에 필요한 데이터 목록

### 4.1 손 없는 날 데이터 (기본)

| 항목 | 설명 | 예시 |
|---|---|---|
| 음력 날짜 | 음력 월일 | 음력 9월 10일 |
| 양력 날짜 | 해당 음력 날짜의 양력 | 양력 날짜는 음력 표로 계산 |
| 손 없는 날 여부 | 음력 끝자리 9 또는 0 | 참/거짓 |
| 방위 (선택) | 손의 방위. 출처 차이가 있어 기준 확정 필요 | 확인 필요 |
| 요일 | 양력 기준 요일 | 표시용 |
| 공휴일 여부 | KASI 특일 정보 기반 | 표시용 |

### 4.2 길일 데이터 (확장)

```json
{
  "date": "2027-03-10",
  "lunar": "2027-02-xx (예시, 실제 값은 음력 표로 계산)",
  "son_free": true,
  "hwangdo": { "type": "황도", "deity": "청룡" },
  "geonje": "成",
  "use_fit": { "이사": "good", "결혼": "neutral" },
  "notes": ["기준 출처 및 차이 표시"]
}
```

- 위 예시는 구조만 보여 준다. 실제 값은 계산해서 채워야 하며 여기 적은 날짜는 검증되지 않았다.
- 용도별 판정(good, neutral, avoid)은 기획에서 정하고, 어느 출처를 따랐는지 함께 적는다.

## 7. 관련 법규·정책

### 7.1 오락·참고 목적 고지와 미신성 표현
- 법령으로 정해진 고지 문구는 찾지 못했다. 이 분야는 민속 관례이므로 "과학적으로 검증되지 않았다", "참고용", "결정은 본인과 전문가 판단" 같은 고지가 기획 기준이 된다. 문구 수위는 확인 필요.
- 프로젝트의 기존 기준(COMPLIANCE.md 11장)은 오락 고지, 보장·예언 표현 금지, 금지 표현 목록 검사다. 손 없는 날 기능에도 같은 방식을 적용하는 것을 권한다.
- 길일을 따르지 않아 생긴 손해(예: 날짜를 골랐는데 이사업체 예약이 안 됨)에 대해서는 책임을 지지 않는다는 취지의 고지가 필요할 수 있다. 법률 확인 필요.

### 7.2 표시광고법 (과장 광고)
- 표시광고법 제3조 제1항은 부당한 표시·광고를 거짓·과장, 기만, 부당 비교, 비방으로 나눈다(요약 검색 기준, 공정위·소비자24 안내 요약).
- "이 날에 이사하면 좋은 일이 생긴다", "사업이 잘된다" 같은 표현은 효과를 보장하는 것으로 읽힐 수 있다. 과장 광고로 볼 위험이 있다. 법률 확인 필요.
- 이사업체 제휴 문구(예: "가장 싼 날")는 가격이나 혜택 표시 규정도 함께 봐야 한다. 확인 필요.
- 점술·운세 광고에 대한 공정위 제재 사례는 이번 검색에서 찾지 못했다. 확인 필요.

### 7.3 개인정보
- 날짜만 입력해서 계산하는 손 없는 날 달력은 개인 정보가 필요하지 않다. 이 경우 개인정보 문제는 작다.
- 띠, 생년월일, 사주 기반 택일처럼 개인 정보를 입력받는 기능을 넣으면 운세 기능과 같은 동의·연령 흐름(만 14세 미만 차단, 입력값 비저장)을 따라야 한다(COMPLIANCE.md 1장, 11장 기준). 법률 확인 필요.

### 7.4 광고 플랫폼 정책
- Google AdSense: 조사에서 점술·운세 콘텐츠를 금지한다는 규정은 찾지 못했다(요약 검색 기준, 공식 정책 페이지 원문은 확인하지 못함). 확인 필요.
- AdSense는 광고주 쪽 민감 카테고리로 "Astrology & esoteric"(점성술, 신비주의)를 두고 있으며, 퍼블리셔가 차단할 수 있다(요약 검색 기준).
- "Made for kids" 콘텐츠에서는 점성술·신비주의 광고가 제한된다(요약 검색 기준). 아동 대상이 아니면 해당하지 않을 수 있다.
- 과장되거나 사실과 다른 주장은 오인 관련 정책에 걸릴 수 있다(요약 검색 기준, 추론).
- 프로젝트는 AdFit을 쓰는 것으로 되어 있다(COMPLIANCE.md 4장). AdFit의 점술·운세 심사 기준은 이번 조사에서 확인하지 못했다. 확인 필요. 꿈 해몽 기능에서도 같은 확인이 남아 있다.

### 7.5 사행성
- 손 없는 날 달력은 돈을 걸거나 보상을 주는 구조가 아니므로 사행성 문제는 작아 보인다. 룰렛이나 뽑기 같은 기능을 붙이면 달라진다. 법률 확인 필요.

## 9. 기획자에게 넘길 열린 질문

1. 범위: 손 없는 날만 할지, 황도·건제12신·생기복덕까지 넣을지 정해 주세요. 넣는다면 어느 용도(이사, 결혼, 개업 등)부터 할지도 정해 주세요.
2. 계산 기준: 음력 소월(29일까지만 있는 달)에서 29일·30일을 어떻게 처리할지 정해 주세요. 출처 한 곳을 기준으로 삼을지, 여러 곳을 비교해 표시할지도 정해 주세요.
3. 방위 표시: 손의 방위(4방위 또는 8방위)를 화면에 보여 줄지, 보여 준다면 어떤 설명을 따를지 정해 주세요.
4. 연도 범위: 음력 표는 2049년까지, 절기 표는 2028년까지다. 황도·건제를 2029년 이후에도 보여 줄지 정해 주세요. 그렇다면 절기 데이터를 더 받아야 하며, 운세 기능의 F-1 작업과 같이 처리할지도 정해 주세요.
5. 개인 정보: 띠 충, 사주 기반 택일처럼 생년월일을 입력받는 기능을 넣을지 정해 주세요. 넣으면 운세 기능과 같은 동의 흐름(만 14세 미만 차단 등)을 적용해야 합니다.

7. 공휴일 표시: 공휴일과 대체공휴일을 같이 보여 줄지 정해 주세요. KASI 특일 정보를 쓰면 출처 표기가 필요합니다.
