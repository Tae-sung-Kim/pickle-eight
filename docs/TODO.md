## 배포 공통

- 약관·방침 시행일(`EFFECTIVE_DATE`)은 2026-11-25로 고쳤다(`src/app/terms/page.tsx`, `src/app/privacy/page.tsx`). 실제 배포일이 다르면 두 줄만 다시 고친다.
- 배포 뒤 구글·네이버 서치어드바이저에서 sitemap과 새 주소 재수집을 요청한다(`/meal`, `/lucky-draw/*`, `/`, `/lotto`, `/fortune/compatibility*`, `/no-son-days*`).
- Vercel 환경변수에 `NEXT_PUBLIC_ADFIT_UNIT_ID_BOTTOM`(전역 하단 광고 단위)을 넣는다. 없으면 하단 광고만 빠진다.
- KASI(data.go.kr) 키가 대화에 노출됐다. 재발급하고 `.env`와 Vercel 값을 바꾼다.
- 네이버 검색광고 키워드 도구 검색량 조회는 기능별 항목에 있다(점심·저녁·아침, 운빨 뽑기, 궁합, 손 없는 날).

# 다음 기능 (리서치 → 기획 순서로 진행)

우선순위(2026-11-24 사용자 지정): 궁합 테스트 → 공유 기능 → 나머지. 다국어는 맨 뒤.

1. 공유 기능 후속: 타로 공유는 2026-11-26에 개발했다(`docs/share-tarot/`). 궁합 공유 연결: 1차의 `fortune-compatibility-share.util.ts`, `compatibility-share-card.component.tsx`가 화면에 붙어 있지 않다(2026-11-26 확인). 연결하거나 지운다. 제외 유지: 사주, 꿈 해몽, 로또 기록·채점·분석·시뮬레이터.
2. 손 없는 날 달력 2차 후보: 황도·건제12신·생기복덕·생년월일 기능, 공휴일, 길일(이사·결혼·개업) 달력. 이름 궁합은 보류.
3. 로또 QR 코드: 입력 없이 사진으로 바로 접속할 수 있게 한다.
4. 뭐먹지 메뉴를 더 늘리려면 새 기획이 필요하다. 2026-11-24에 점심 90, 저녁 150, 아침 65개로 늘렸다(`docs/menu-add/plan.md`). 그 밖에 이 사이트에 맞는 메뉴를 계속 추가한다.
5. 홈 재구성 후속(`docs/home-reposition/`):
   - 푸터·헤더 로고가 로또 공 모양(`lotto-ball`, 숫자 8)이다. 홈 톤에 맞게 바꿀지 별도 작업으로 정한다.
   - PC 헤더 1024px·1280px에서 드롭다운(특히 운빨 뽑기)이 화면 안에 열리는지 브라우저로 확인한다. 헤더 메뉴가 한 줄이고 넘치지 않는 것은 손 없는 날 e2e로 확인했다(7그룹).
6. 뭐 먹지 지도 검색 메모: 처음에는 "내 위치 공유로 주변 검색"을 원했으나 카카오·네이버·구글 웹 검색 URL이 좌표 기준 주변 검색을 공식 지원하지 않아 동네 이름 입력으로 정했다(2026-11-24). 위치 권한은 쓰지 않는다. 나중에 지도 서비스가 웹 URL 좌표 검색을 지원하면 좌표 방식을 다시 검토한다.
7. 다국어 지원 검토: 일단 영어만. 맨 마지막에 진행한다. 리서치부터 시작한다.
   - 어떤 메뉴가 영어 사용자에게 의미가 있는지 나눈다. 한국 전용(로또, 사주, 한국식 메뉴, 카카오·네이버 지도)과 그대로 쓸 수 있는 것(운빨 뽑기, 타로 등)을 구분한다.
   - 주소 구조(`/en` 하위 경로 등), `hreflang`·sitemap·메타데이터, 라이브러리 선택(Next.js App Router i18n, 예: `next-intl`)과 새 라이브러리 라이선스 문서 갱신 여부를 조사한다.
   - 약관·방침·법적 고지(영어판), 광고(AdFit은 국내 중심이라 영어 방문자용 광고 정책), 번역 품질과 문구 검수 방식, 서비스 문구 금지어 검사(`copy-rule`)의 영어판 필요 여부를 확인한다.

3. 전체적인 문구 정리.
4. 타로, 운세: 개발 완료 후 전체적으로 검증이 필요하다.
5. 루트 404 화면(`src/app/not-found.tsx`)에 꿈 해몽 허브 링크 추가 검토. 사이트 전체 화면이라 사용자 승인이 필요하다.
6. 루트 `src/app/loading.tsx` 스트리밍 영향 점검 (전 페이지 영향, 별도 작업으로 로또 포함 검토 필요)
   - JS를 끄면 본문이 `hidden` 영역에 남아 보이지 않는다. 서버 HTML에는 본문이 있다(2026-11-05 알려진 한계 수용, `docs/tarot/status.md`).
   - 없는 주소(404)에서 로드 직후 h1이 잠깐 2개로 잡혔다가 1개로 돌아온다(모바일에서 간헐적, 운영 빌드 확인).
7. 기존 e2e 중복 정리: QA 범위 규칙은 2026-11-24에 `CLAUDE.md`, `.claude/agents/qa.md`, `.claude/agents/planner.md`에 반영했다. 운빨 뽑기 e2e는 새 규칙으로 정리했다(33개에서 21개).

   - 점심 e2e가 전체 병렬 실행에서만 가끔 실패했다(qa 실행에서 한 번, 단독 실행과 이후 전체 실행은 통과). 다시 나오면 원인을 확인한다.

8. API 요청 제한 보강: 트래픽이 늘거나 CSV 내보내기 남용이 보이면 검토한다.

   - `docs/archive/lucky-draw/qa-report.md` 등에 남은 옛 실패 기록과 임시 문구를 정리한다.
   - 운세 `fortune-lunar.util.ts`와 공용 `src/lib/lunar-calendar.ts`의 중복이 남았는지 한 번 본다(2026-11-25에 달 길이·연도 행 함수는 공용으로 바꿨다).
10. 돌림판 결과 가리기의 한계: 칸 글자는 숨기지만 칸 경계선과 바늘 위치로 칸을 셀 수 있다. FAQ에 한계를 적었다. 더 막으려면 설계부터 다시 봐야 한다.
