- 2026-11-19: 상황 선택형, AI 자유 서술, 꿈 기록은 1차 범위 밖으로 기록하고 후속 후보로 둠
- 2026-11-19: 기획 승인. plan 열린 질문은 모두 기본안 채택
  - 소재 120개, slug는 영문 로마자, 용꿈 제외(12지 동물은 용을 뺀 11개)
  - 메뉴는 그룹 "꿈 해몽" + 하위 "꿈 소재 찾기" 1개. 메뉴 색 토큰 재사용 여부는 UI/UX 단계에서 정함
  - 상담 안내는 모든 상세 페이지 하단에 노출
  - 검색창 위기 표현 감지 시 상담 안내 표시(결과는 막지 않음, 브라우저 안에서만 감지)
  - 동의 게이트 없이 공개, 연령 게이트 없음
  - 법률 검토 없이 운영자 위험 수용
  - 면책 초안 문구는 plan.md 그대로 승인
  - 분량 기준 공백 포함 300자 이상, 미달은 출시 전 검사 실패
  - 띠 동물 소재에 띠별 운세 링크(동의 안내 포함), 홈은 자동 노출만
