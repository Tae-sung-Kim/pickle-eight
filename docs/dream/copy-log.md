# 꿈 해몽 문구 작성·검수 이력

이 문서는 꿈 소재 풀이 문구의 작성자, 작성일, 검수 상태를 기록한다. 형식은 `docs/tarot/copy-log.md`, `docs/fortune/copy-log.md`와 `docs/dream/design.md` 11장을 따른다. 작성 이력은 문구 데이터에 넣지 않고 이 문서에만 둔다. 소재 표의 헤더와 첫 열(slug)은 바꾸지 않는다.

## 작성 원칙

- 외부 풀이 문장 미참조: 타 해몽 책, 사이트, 앱의 풀이 문장을 보지 않는다. 복사, 번역, 어순 변경, 일부 단어 교체를 하지 않는다. 작성 중에는 웹 검색으로 풀이 문장을 찾지 않으며, AI 입력에 다른 사이트의 문장을 붙여 넣지 않는다.
- 소재 이름 목록을 외부에서 통째로 옮기지 않는다. 원전, 고서를 인용하거나 출처를 주장하지 않는다("민간에서 전해 온 풀이"로만 쓴다).
- 구성: 한 줄 요약 1문장(20~80자), 민간 풀이 3~5문장, 요즘 생각해 볼 점 2~3문장, FAQ 2개. 민감 소재는 완화 문장 1~3개를 더한다. 민간 풀이와 생각해 볼 점의 합은 공백 포함 300자 이상이다.
- 톤: 합니다체. "민간에서는 ~로 풀이해 왔습니다", "요즘 관점에서는 ~", "~해 보시는 것도 방법입니다"를 기본으로 하되 문장 끝이 반복되지 않게 변주한다. 단정, 예언, 보장 표현과 길흉 라벨을 쓰지 않는다.
- 죽음·불안 소재는 공포를 키우는 묘사를 하지 않고, 완화 문장과 전문가 상담 안내를 넣는다. 죽음 소재에는 실제 죽음과 이어지지 않는다는 설명을 넣는다.
- 로또, 번호, 복권 연상 표현, 투자·도박 권유, 태몽·성별·임신 표현을 쓰지 않는다. 금지 목록은 `src/features/dream/constants/dream-copy-rule.constant.ts`를 따른다.
- 소재마다 그 소재에만 맞는 문장을 넣고, 소재 이름만 바꾼 같은 문장 틀을 반복하지 않는다.
- 오타와 의미 오류 검수는 사용자가 한다. 외부 문서와 대조하는 검수는 하지 않는다.

## 한계

- 웹 검색 점검은 전수 검사가 아니다. "일치 없음"은 "없다"가 아니라 "이번 검색에서 찾지 못했다"는 뜻이다.
- 2026-11-19에 묶음별 1차 샘플 점검을 했다. 결과는 "웹 검색 샘플 기록"과 "묶음별 점검 요약" 절에 있다. 샘플 10개를 포함한 문구는 점검 전에 외부 문장 참조 없이 처음부터 작성했다.

## 묶음 코드

`DR-S` 샘플 10, `DR-1` 동물, `DR-2` 사람·관계, `DR-3` 신체, `DR-4` 자연·날씨, `DR-5` 행동·상황, `DR-6` 사물·장소·재물, `DR-7` 죽음·사고, `DR-N` 고지·FAQ·SEO·메뉴 문구. 샘플 소재는 `DR-S`로 남긴다.

- DR-1: 개, 말, 쥐, 소 문장은 질의에 포함되지 않았다. 점검 필요.
- DR-2: 직장 동료, 가족, 어머니 문장 12개는 질의에 포함되지 않았다. 점검 필요.
- DR-3: 피, 손 문장 7개는 질의에 포함되지 않았다. 점검 필요.
- DR-4: 비, 산, 바람, 눈 문장 12개는 질의에 포함되지 않았다. 점검 필요.
- DR-5: 떨어지는 꿈 문장 8개는 질의에 포함되지 않았다. 점검 필요.
