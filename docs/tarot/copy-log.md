# 타로 카드 문구 작성·검수 이력

이 문서는 카드 해석 문구(키워드, 요약)의 작성자, 작성일, 검수 상태를 기록한다. 형식은 `design.md` 3.3을 따른다.

## 작성 원칙

- 외부 해석 문장 미참조: 타 사이트, 책, 앱, 다른 타로 서비스의 문장을 복사, 번역, 어순 변경하지 않는다. 작성 중에는 웹 검색과 외부 문장 참조를 하지 않고, 카드의 일반적 의미 아이디어만 바탕으로 처음부터 새로 쓴다.
- 톤: 합니다체, "~일 수 있습니다" 형태를 기본으로 하되 문장 끝이 반복되지 않게 변주한다(예: "~하는 시기일 수 있습니다", "~를 돌아보게 합니다", "~해 보는 것도 방법입니다"). 단정, 과장, 공포 조장, 효과 주장을 쓰지 않는다. 투자, 도박, 복권, 로또, 의료, 법률 단정을 쓰지 않는다.
- 구조: 카드당 정방향 키워드 3개(명사형 짧은 단어) + 요약 1~2문장, 역방향 키워드 3개 + 요약 1~2문장.
- 역방향 렌즈: "정반대"가 아니라 막힘, 지연, 내면, 과잉 중 카드에 맞는 하나의 렌즈로 쓴다.
- 불안을 줄 수 있는 카드(죽음, 탑, 악마 등)는 "끝, 전환, 돌아볼 신호"처럼 완화한다. 죽음 카드는 `note` 필드에 "실제 죽음이 아니라 끝맺음과 전환" 설명을 둔다.
- 카드 그림 묘사를 문구에 끌어오지 않는다(그림은 자체 제작 도형이다).
- 금지 표현: `design.md` 7.1, `plan.md` "표현 규칙", `src/features/tarot/constants/tarot-copy-rule.constant.ts`의 목록(100%, 적중, 정확히 맞, 백발백중, 족집게, 무조건, 반드시, 확실히, 보장, 틀림없, 운명이 바뀐, 인생이 바뀐, 운명을 바꿔, 대박, 합격합니다, 헤어집니다, 성공합니다, "게 됩니다" 계열 어미). 상표성 명칭(Rider-Waite, 라이더-웨이트, 웨이트 등)도 쓰지 않는다.
- 오타와 의미 오류 검수는 사용자가 한다. 외부 문서와 대조하는 검수는 하지 않는다.
- 작성 이력: CT-3a 위치 안내·분야 예시·FAQ | 작성자 AI(Claude, frontend-dev 에이전트) | 2026-11-04 | 상태 초안, 사용자 검수 대기
- 작성 이력: CT-3b 오늘의 타로·3장 타로 가이드 본문과 질문 placeholder 2건 | 작성자 AI(Claude, frontend-dev 에이전트) | 2026-11-05 | 외부 참조 없이 처음부터 작성, 합니다체, 메이저 22장 승인 톤 기준 | 상태 초안, 사용자 검수 대기

## 웹 검색 샘플 확인 기록

CT-4에서 완성된 문구의 대표 문장을 웹 검색해 같은 문구가 있는지 확인한다. 같거나 거의 같은 문장이 나오면 새로 쓰고 아래 표의 해당 칸에 "수정함"으로 남긴다.

확인 범위와 방법 (2026-11-05, researcher):

- 전수 검사가 아니다. 사용자가 확정한 샘플 규모(메이저 8장, 마이너 수트별 4장, FAQ·가이드·위치 안내 각 2문장 이상)에 따라 38개 문장을 골라 확인했다. 샘플에 들지 않은 카드는 이 확인을 하지 않았다.
- 카드 요약 문장의 앞 한 문장(또는 그 핵심 구절)을 따옴표로 묶어 웹 검색에 넣었다. 메이저는 8장 모두 정방향 첫 문장을 확인했고, 그 가운데 바보, 죽음, 탑, 악마는 역방향 첫 문장도 추가로 확인했다. 마이너는 수트별 에이스 1장, 코트 1장, 숫자 2장을 골랐다.
- 검색 도구는 완전 일치(문자열 그대로)만 돌려주는 검색이 아니다. 따옴표 문장이 그대로 들어 있는 페이지가 한 건도 나오지 않았다는 뜻이며, 검색 색인에 없는 페이지까지 배제한다는 뜻은 아니다. 샘플 확인의 한계로 둔다.
- 결과 표기: "일치 없음"은 같은 문장이나 어순만 다른 수준의 문장이 결과에 없다는 뜻이다. "일치 없음(일반 어구)"은 비슷한 취지의 설명은 있으나 문장 자체는 다른 경우다.
- 일치 있음(수정 필요) 문장: 0건. 따라서 이번 확인에서 새로 써야 할 문장은 없다.

## 오타·문장 흐름 교정 기록 (2026-11-05)

- 확인 범위: 카드 78장(정·역방향 keywords, summary), FAQ 10쌍, 위치 안내, 질문 예시·placeholder, 가이드 본문, SEO 문구, 메뉴 설명, `tarot-notice.constant.ts`.
- 수정: 약 42곳. 주요 유형은 같은 어구 반복 해소, 주어·서술어 호응, 직역투("요구됩니다" → "필요합니다"), 오독 가능한 단어 순화("지침" → "피로"·"외로움", "절도" → "적절함", "외면" → "거리 두기"), 띄어쓰기("자기 만족" → "자기만족"), 가이드 논리 충돌 정리.
- 수정 후 확인: `pnpm typecheck`, Biome, `e2e/tarot-copy.spec.ts`(50건 통과, 금지 표현·합니다체 검사 포함).
