## 참고

- "아침·브런치" 스크린리더 읽기(ui-ux 접근성 요청)는 직접 들어 보지 않았다. 접근성 이름은 보이는 글자와 같다(e2e에서 `getByRole('radio', { name: '아침·브런치' })` 가능).
- 회전은 1초라 "회전 중 끼니 변경 무시" 테스트는 같은 틱에서 두 클릭을 보낸다(Playwright 클릭 두 번 사이에 회전이 끝난다).
- 모바일 프로젝트는 설정상 `@smoke`만 돌려 AC-2~4, 16~26 테스트는 데스크톱만 실행된다.
- 320px 화면 레이아웃은 스크린샷과 스크립트 측정으로 확인했다. 6칸 칩은 2열 격자(너비 124px)이고 끼니 칸 3개는 한 줄이며 지도 링크는 모바일에서 세로다. 칩과 링크 안 글자 잘림은 없었다.
