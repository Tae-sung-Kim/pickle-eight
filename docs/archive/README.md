# 보관 문서 (archive)

끝난 작업의 기록이다. 평소에는 읽지 않는다. 옛 결정의 이유가 필요할 때만 연다. 지우지 않고 git 기록과 함께 둔다.

- `lunch/`: 점심 추천 문서 전체. `menu-meals/`(뭐 먹지)로 대체됐다.
- `fortune-v2/`, `tarot-v2/`, `e2e-cleanup/`: 지난 개편과 e2e 정리 기록.
- `<기능>/dev-tasks.md`: 개발 작업 분해 기록(작업이 끝나면 옮긴다).
- `<기능>/qa-report.md`: QA 결과 기록. 배포 전 수동 확인이 남은 기능(`share`, `meal-location`, `compatibility`)은 배포 뒤에 옮긴다.

다른 문서에서 이 파일들을 가리키는 경로는 `docs/archive/...`로 고쳐 두었다. 기능 폴더의 `status.md` 표에 적힌 `dev-tasks.md`, `qa-report.md` 파일명은 옛 이름 그대로이니 `docs/archive/<기능>/`에서 찾는다.
